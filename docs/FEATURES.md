### AI 系统（M3/M4 — 项目技术难点核心）
- 🔴 导航层：NavigationAgent3D 官方寻路（navmesh 烘焙）
- 🔴 感知层：视线/遮挡检测 + 听觉（脚步声/枪声事件），参考 mtrebi/AI_FPS
- 🔴 决策层：轻量行为树（5-10 节点，参考 BehaviorTree 思路）+ 分层状态机（待机/巡逻/追击/交战/守点/撤退）
- 🔴 反应层：拟人化对枪（瞄准加速度、反应时间 150-400ms、压枪误差），参考 CS2-Bot-Improver 人格参数思路
- 🔴 团队层：角色分配（突击/支援/狙击/守点）+ 简单呼叫（报点/请求支援），参考 Q3 ai_team.c 思路
- 🔴 三档难度（简单/普通/困难）以拟人化参数实现：
  - 简单：反应 400-700ms / 瞄准误差大 / 压枪精度低 / 感知范围缩短
  - 普通：反应 250-450ms / 误差中 / 精度中 / 标准感知
  - 困难：反应 150-250ms / 误差小 / 精度高 / 感知范围延长

## 核心数值规格（已定稿，见设计文档 §4）

| 规格 | 值 |
|------|-----|
| 单位血量 | 统一 100 HP（玩家与 9 个 AI 一致，v1.0 无护甲） |
| 部位倍率 | 头 ×2.5（上限）/ 躯干 ×1 / 四肢 ×0.8；狙击、霰弹中心弹丸 ×1.5 例外 |
| 一枪必杀 | 仅 AWM 爆头 120 满足（AK-47 爆头 62.5、匕首头部 87.5 均大残） |
| TTK 基调 | 躯干击杀：步枪 4 发 / 冲锋枪 5 发 / 手枪 5 发；霰弹近距 2 发；狙击躯干 2 发（大残补枪）；手雷大残不秒杀 |
| 衰减模型 | 分段阶梯（非线性），衰减下限永不为 0；霰弹逐弹丸独立衰减 |
| 命中判定 | 枪械统一 hitscan，投掷物为弹道 |
| AI 数量 | 9 bot：4 队友 + 5 敌人 |
