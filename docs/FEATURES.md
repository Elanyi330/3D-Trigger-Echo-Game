### 地图与模式（M2 — 双模式核心循环）
- 🔴 大图「回声哨站」（约 60m×60m）— 目标点占点：中道 + 双翼 + 目标点，多点位攻防迂回
- 🔴 小图「弹痕仓库」（约 30m×30m）— 经典团战：紧凑交火、掩体密布、快节奏对枪
- 🔴 几何体 BoxMesh 组合 + 少量贴图，程序化生成优先，为 navmesh 预留烘焙通道
- 🔴 模式一 目标点占点：1 中立目标点 + 攻方占据守 30 秒 / 回合限时 2 分钟 / 死亡在己方安全区复活（复活冷却）/ 按回合计分，先达 7 分获胜
- 🔴 模式二 经典团战：5v5 全灭即胜 / 无复活（死亡观战至局末）/ 打满 7 局先胜 4 局
- 🔴 回合状态机（参考 CS gamerules 结构，读源码不抄代码）：倒计时/准备/进行/结算

### AI 系统（M3/M4 — 项目技术难点核心）
- 🔴 导航层：NavigationAgent3D 官方寻路（navmesh 烘焙）
- 🔴 感知层：视线/遮挡检测 + 听觉（脚步声/枪声事件），参考 mtrebi/AI_FPS
- 🔴 决策层：轻量行为树（5-10 节点，参考 BehaviorTree 思路）+ 分层状态机（待机/巡逻/追击/交战/守点/撤退）
- 🔴 反应层：拟人化对枪（瞄准加速度、反应时间 150-400ms、压枪误差），参考 CS2-Bot-Improver 人格参数思路
- 🔴 团队层：角色分配（突击/支援/狙击/守点）+ 简单呼叫（报点/请求支援），参考 Q3 ai_team.c 思路
- 🔴 三档难度（简单/普通/困难）以拟人化参数实现：
  - 简单：反应 400-700ms / 瞄准误差大 / 压枪精度低 / 感知范围缩短
  - 普通：反应 250-450ms / 误差中 / 精度中 / 标准感知
  - 困难：反应 150-250ms / 误差小 / 精度高 / 感知范围延长

## 核心数值规格（已定稿，见设计文档 §4）

| 规格 | 值 |
|------|-----|
| 单位血量 | 统一 100 HP（玩家与 9 个 AI 一致，v1.0 无护甲） |
| 部位倍率 | 头 ×4.0（对齐 CS2）/ 躯干 ×1 / 四肢 ×0.8；Deagle ×3.9、M4A1-S ×3.475 例外 |
| 一枪必杀 | 爆头：AK 144 / AWP 460 / Glock 120 等（单发×4.0≥100 即必杀）；躯干：AWP 115、霰弹近距 234、匕首背刺 180 |
| TTK 基调 | 躯干击杀：步枪 4 发 / SMG 4-5 发 / 手枪 4-5 发；霰弹近距 1 发；狙击躯干 1 发（AWP）；手雷中心 98 不秒杀 |
| 衰减模型 | 分段阶梯（非线性），衰减下限永不为 0；霰弹逐弹丸独立衰减；CS2 基准 500u 处 2%-55% |
| 命中判定 | 枪械统一 hitscan，投掷物为弹道 |
| AI 数量 | 9 bot：4 队友 + 5 敌人 |
