## T19：伤害归因通道

### 接口块（精确签名）

```gdscript
# Enemy.gd / player_life.gd / 各伤害接收方：
#   take_damage(dmg: float) → take_damage(dmg: float, attacker: Node = null)
#   （attacker 默认 null 兼容既有调用；died 信号追加可选参数：
#    信号定义改 signal died(attacker: Node = null)——Godot 4 信号默认参数兼容既有 emit 无参）
# WeaponCore.hit_landed 已有 target/damage——hitscan 结算处把 shooter 透传：
#   WeaponCore 增 var shooter: Node（setup 时由装配方设置；玩家=player、bot=bot body）
# MeleeController：近战命中 take_damage(dmg, shooter)
# Grenade：explode 伤害结算 take_damage(dmg, thrower)（Grenade 增 var thrower: Node，
#   WeaponManager 生成时设置）
# L_M2 归因接线：
#   _on_enemy_died(e, attacker)：attacker 为玩家 → _stats.add_kill("player")；
#   attacker 为敌 bot → 无（TDM 敌杀敌不存在，友伤过滤已禁）；attacker 为友军 →
#   M3.5 归因接入点注记。_on_player_died：attacker 为具体敌 bot → 该 bot 名 add_kill
#   （原 _match.add_enemy_kill() 改归因后仍保比分 +1）
```

### 语义规格

1. 三通道透传：hitscan（WeaponCore shooter）/近战（MeleeController shooter）/
   爆炸（Grenade thrower）——attacker 仅记录不改伤害数值（归因与结算分离）。
2. Enemy._die() 的 died 信号带 attacker；L_M2 `_on_enemy_died(e, attacker)` 归因
   （attacker==_player 或玩家武器链 → "player"；null（手雷炸死但 thrower 已释放等）
   → 记 "player" 兜底？——不：null → 不记击杀只记死亡（保守诚实），注释说明）。
3. 玩家死亡：PlayerLife.died 带 attacker → L_M2 归因具体敌 bot 名 add_kill。
4. 既有调用点机械适配（take_damage 单参调用不加参仍兼容默认 null）。

### 测试规格（test/unit/test_damage_attribution.gd，TDD）

1. `test_enemy_take_damage_with_attacker`：attacker 透传存储（击杀时 died 信号参数正确）
2. `test_hitscan_attribution`：WeaponCore shooter 设置 → 命中后 died(attacker==shooter)
3. `test_grenade_attribution`：thrower 设置 → 爆炸致死 died(attacker==thrower)
4. `test_melee_attribution`：近战致死 → attacker 正确
5. `test_l2_kill_attribution`（集成）：装配 L_M2 → bot 击杀敌 bot 场景不存在（友伤过滤）
   → 断言：玩家击杀敌 bot 归因 "player" 战绩 +1（既有路径回归）；敌 bot 击杀玩家
   （bot 武器未装配→T20 前用 take_damage 直调带 attacker）→ 敌 bot 名 add_kill
   （stats 查询断言）

## T20：bot 武器装配 + 射击（新文件 Levels/M2_TDM/bot_combat.gd）

### 接口块（精确签名）

```gdscript
class_name BotCombat
extends Node

signal shot_fired(ammo_left: int)   # 黑板弹药键刷新源（装配方接）
signal reload_started
signal reload_finished

const AIM_EYE := Vector3(0, 1.65, 0)     # 瞄准原点（bot 眼睛高度）
const AIM_ERROR_BASE := 0.35              # m：15m 处基线散布半径（≈35% 命中率，M3.6 .tres 迁移注记）
const AIM_CONVERGE := 0.6                 # s：瞄准收敛时间（接敌后误差按时间收缩）
const AIM_ERROR_MIN_RATIO := 0.15         # 收敛下限（σ 不低于基线 15%）
const BURST_MIN := 3                      # 短点射发数下限（AK）
const BURST_MAX := 5
const BURST_GAP_MIN := 0.3                # s：点射间隔下限
const BURST_GAP_MAX := 0.6

var body: Enemy
var manager: WeaponManager               # 4 槽同玩家资源
var aim_camera: Camera3D                 # 瞄准锚（bot 头部，非渲染相机）

func setup(b: Enemy, m: WeaponManager, cam: Camera3D) -> void
func aim_tick(target: Node, delta: float) -> void   # 每帧瞄准（误差+收敛）
func try_burst() -> void                            # 短点射驱动（Brain fire_intent 消费）
static func error_radius(base: float, converge_t: float,
        elapsed: float) -> float                    # 纯函数：σ(t)=base×clamp(1−t/converge,0.15,1)
```

### 语义规格

1. **装配**（L_M2 `_attach_bot_ai` 扩展）：bot Enemy 下挂 WeaponManager
   （WEAPON_RES 同玩家 4 资源）+ aim_camera（Camera3D，position=AIM_EYE 相对 bot、
   current=false 非渲染）+ BotCombat。WeaponManager.set_head 不调（bot 无视图）；
   set_weapon_view 不调（_throw_origin 回退相机）。WeaponCore.shooter = bot body
   （T19 透传）。
2. **瞄准**：aim_tick——目标胸口（CHEST y=1.2）为期望点；`error_radius(0.35, 0.6,
   _aim_elapsed)` 得 σ → 每 0.15s 重采样一次高斯偏移（水平两轴，均值 0 方差 σ²，
   种子随机）→ 实际瞄点 = 期望点 + 偏移 → aim_camera.look_at(实际瞄点)。
   接敌（_aim_elapsed 归零）后收敛：0s 全误差 → 0.6s 后 σ 降至 15%。失视重置。
3. **短点射**：Brain fire_intent 活跃期间——burst 状态机：发射 BURST_MIN..MAX 发
   （每物理帧 manager.try_fire()，WeaponCore 射速自限）→ 间隔 BURST_GAP 随机 →
   下一轮。目标失视/切枪/换弹中断点射。
4. **弹药黑板键真实化**：manager 的 weapon_ammo_updated/shot_fired → 黑板
   mag_frac（mag/magazine）/reserve 真实值（替代 T18 装配的静态注入 1.0）；
   grenade_left 由 manager 资源口径（T22）。
5. **换弹**：Brain RELOAD 状态 → manager.start_reload()（reload_started/finished
   信号回写黑板 reload_done 键——T13 的注入键转真实源）。
6. 玩家手感零改动：新逻辑全在 bot_combat.gd + manager 的 bot 专用路径。

### 测试规格（test/unit/test_bot_combat.gd，TDD）

1. `test_error_radius_pure`：σ(0)=base；σ(converge)=base×0.15；中间单调递减
2. `test_aim_converges_on_target`：目标静止 → aim_camera 前向与目标方向夹角随时间
   收敛（0.6s 后 < 初始夹角）
3. `test_burst_fire_consumes_ammo`（集成）：装配 L_M2 → bot ENGAGE 注入 → 短点射
   一个 cycle → manager 弹匣减少 ∈ [BURST_MIN, BURST_MAX]
4. `test_mag_frac_real_source`：射击后黑板 mag_frac 与 core.get_ammo 一致
5. `test_reload_done_signal`：RELOAD 注入 → start_reload → finished 后黑板
   reload_done==true
6. `test_bot_shot_hits_player`（集成）：bot 视线内玩家 15m 静止 → 点射 → 玩家
   take_damage 收到伤害（PlayerLife hp 下降；出生保护关闭口径）
7. `test_accuracy_ballpark`：静止玩家 15m × N 发（大样本，如 200 发）→ 命中率
   ∈ [0.2, 0.5]（35% 基线带 ±15% 带宽——参数化阶段前 ballpark 不钉死精确值，
   注释说明）
