## 一、数据口径与全局约定（照搬 CS2，覆盖企划书旧值）

| 项目 | CS2 值 | 覆盖说明 |
|------|--------|----------|
| 爆头倍率 | **×4.0**（全武器统一；Deagle ×3.9、M4A1-S ×3.475 例外） | 覆盖企划书 ×2.5 |
| 一枪必杀 | 满足"单发伤害 × 4.0 ≥ 100"即一枪爆头；躯干一枪仅 AWP/SSG 类 | 覆盖旧规则 |
| TTK | 步枪 4 发、SMG 4-5 发、手枪 4-5 发、霰弹近距 1-2 发、狙击躯干 1 发（AWP） | 覆盖旧基调 |
| 移速修正 | 以 250 u/s = 100% 为基准，武器自带 u/s 值（非百分比修正） | 覆盖旧百分比 |
| 换弹 | 单值（CS2 无战术/空仓之分；霰弹逐发装填分首发/后续） | 覆盖旧双值模型 |
| 后坐力 | Recoil Pattern 二分：**Set Pattern**（固定弹道）/ **Random**（随机） | 压枪曲线模板 |
| 穿甲 | 百分比（AK 77.5%、AWP 97.5%…）；本项目 v1.0 无护甲系统，穿甲字段保留但当前恒为全额 | — |

## 五、待校准项（公开数据缺失，开发时定）

| 字段 | 状态 |
|------|------|
| 切枪/换枪时间（deploy time） | 仅 AK ≈0.3s 可查，其余 M1 开发时按 CS2 手感定（约 0.5-1.0s） |
| 后坐力曲线逐发分布 | 公开数据仅给出标量；M1 采用 CS2 固定弹道（Set Pattern）简化模型：前 3-5 发垂直上升 → 水平摆动 |
| 首发精度角度值 | 公开数据为相对值（AK 极高）；M1 以腰射/开镜散布角度参数化 |
| 弹道穿透（墙） | CS2 为穿透倍数（AK 200%、AWP 250%）；本项目 v1.0 是否引入穿透墙待 M1 定 |
