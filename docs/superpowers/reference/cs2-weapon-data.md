## 单位约定

- CS 长度单位 = Source 引擎 unit，**1 unit = 1 英寸 = 0.0254 m**。
- 本项目移速换算：**250 u/s = 6.35 m/s**（即 1 m ≈ 39.4 u）。
- 刀的"攻击距离"：CS 用眼位出发的 hull trace 判定（非中心距），hull 半径 ~16u、目标 AABB 半宽 ~16u。
  等效"眼到目标中心"最大水平触及 ≈ (trace + 16 + 16) × 0.0254 m。

## 通用机制（CS 行为，本项目已实现）

- **爆头 ×4.0、四肢 ×0.8**（无甲模型；企划书统一 100HP）。
- **换弹余弹保留（总携弹守恒，CS 一贯行为）**：`备弹 -= (弹匣容量 - 换弹前弹匣余量)`，弹匣补满——旧弹匣余弹等效保留（如 10/90 → 换弹 → 30/70，总量 100 不变）。本项目采用此传统规则。
- **开镜期间换弹/切枪自动取消开镜**（CS 式）。
- **近战：单次点击=一次挥击动画，动画期间输入无效，动画完全结束才可下一次**（冷却门控=动画时长；伤害在接触帧单次结算，不叠加）。
