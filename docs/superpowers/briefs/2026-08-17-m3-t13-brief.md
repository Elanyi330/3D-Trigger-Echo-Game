## 接口块（精确签名，照抄）

```gdscript
# Levels/M2_TDM/bot_brain.gd
class_name BotBrain
extends Node

signal state_changed(from: String, to: String)
signal fire_intent(target: Node)            # M3.4 接线
signal switch_intent(slot: int)             # M3.4 接线（0=AK 1=Glock 2=刀 3=雷）
signal throw_intent(target_pos: Vector3)    # M3.4 接线（T16 起发）
signal melee_intent(target: Node)           # M3.4 接线（T16 起发）

enum State { IDLE, PATROL, ALERT, ENGAGE, CHASE, RELOAD, RETREAT }

const REACTION_MIN := 0.3
const REACTION_MAX := 0.6
const CHASE_LIMIT := 30.0
const COVER_MIN := 8.0
const COVER_MAX := 15.0
const COVER_TIER_MAX := "medium"

var body: Enemy
var perception: BotPerception
var blackboard: BotBlackboard
var locomotion: BotLocomotion
var tactical: TacticalPoints
var strategy: BotStrategy   # T15 装配；T13 可为 null（默认 roam 语义）

var state := State.IDLE
var current_target: Node = null

func setup(b: Enemy, perc: BotPerception, bb: BotBlackboard, loco: BotLocomotion,
        tac: TacticalPoints) -> void
func tick(delta: float) -> void
static func reaction_delay(rng_seed: int = 0) -> float
```

## 语义规格

1. **状态转移表（唯一权威，逐字照抄；进入状态即发 state_changed）**：
   ```
   IDLE   --出生保护结束（黑板键 spawn_protection_left ≤0）--> PATROL
   PATROL --听觉事件（heard_event）--> ALERT；--视线内敌对--> ENGAGE；
          --到达巡逻点驻点结束--> PATROL（换点，T14 实现换点，T13 驻点恒 3s）
   ALERT  --视线内敌对--> ENGAGE；--到达 LKP 无发现且超 5s--> PATROL
   ENGAGE --失视（hostile_lost 且无其他可见敌对）--> CHASE；
          --黑板 hp<30--> RETREAT；--黑板 mag_frac<0.3--> RELOAD
   CHASE  --视线内--> ENGAGE；--追击超限（自接敌位置累计路径 > CHASE_LIMIT）
         或 LKP 过期--> ALERT
   RELOAD --黑板 reload_done=true（T16 设）--> ENGAGE（目标仍可见）或 PATROL
   RETREAT --掩体到达或超 8s--> PATROL
   ```
2. **感知接线**（tick 前 setup 时 connect）：
   - `perception.hostile_visible(target, pos)` → current_target=target +
     IDLE/PATROL/ALERT/CHASE 状态时转 ENGAGE + `_reaction_t = reaction_delay()`
   - `perception.hostile_lost(target)` → ENGAGE 且 target==current_target 且无其他
     可见敌对 → CHASE（黑板记接敌位置 chase_origin）
   - `perception.heard_event(kind, pos)` → PATROL/IDLE 时 ALERT + 黑板 alert_pos=pos
     （ALERT 前往=locomotion.set_target(alert_pos)——T14 细化，T13 直设）
3. **反应时间**：ENGAGE 进入时 `_reaction_t = reaction_delay()`；`_reaction_t` 倒计时
   归零前不发 fire_intent；归零后每节流周期（0.2s，同感知节流）对 current_target
   发 fire_intent（持续目标持续发——M3.4 射击节流消费，注释说明）。
4. **tick 顺序**：状态机转移判定 → 状态行为（每状态一个分支）→ 黑板标准键写
   （`state` 字符串名/`target`/`target_lkp`）。
5. **reaction_delay**：rng_seed=0 → `randf_range(REACTION_MIN, REACTION_MAX)`；
   seed>0 → 确定性（seed 映射到区间内定值，规则自定注释）。
6. **黑板键注入协议**（测试与 T14-T16 共用）：`hp`/`mag_frac`/`spawn_protection_left`/
   `reload_done`/`alert_pos`/`chase_origin` 为 Brain 读键；`state`/`target`/
   `target_lkp` 为 Brain 写键。
7. **T13 范围**：目标选择（T14）、策略（T15）、武器（T16）未实现——PATROL 目标 =
   tactical.nearest(body.global_position)（默认行为，注释注明 T14 换 weighted_pick）；
   无切枪无扔雷。
