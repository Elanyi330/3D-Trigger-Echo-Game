## 接口块（精确签名，照抄）

```gdscript
# bot_brain.gd 扩展：
const KNIFE_RUN_DIST := 8.0      # m：切刀赶路阈值（目标导航剩余路程）
const KNIFE_SAFE_DIST := 15.0    # m：切刀安全距离（最近已知敌对 > 此值才切刀）
const PISTOL_MAG_THRESHOLD := 0.2  # 弹匣 ≤20% 触发切手枪评估
const COVER_DIST_MAX := 5.0      # m：无掩体判定（最近掩体 > 此值 → 切手枪续战）
const MELEE_RANGE := 2.0         # m：近身刀人
const GRENADE_CLUSTER_DIST := 10.0  # m：≥2 敌间距 < 此值 = 集群
const GRENADE_RANGE := 20.0      # m：雷程（与 T15 策略常量同值同源注释）

# 黑板键（读）：weapon_slot（当前槽 0=AK 1=Glock 2=刀 3=雷）/

# 黑板键（写）：weapon_slot / intent_switch（目标槽，幂等比较键）/

# 信号（T13 已声明，本任务起真实发）：
```

## 语义规格（全部拍板规则精确实现，逐条照抄）

1. **赶路切刀**：state ∈ {PATROL, ALERT, CHASE} 且 导航剩余路程 > KNIFE_RUN_DIST
   （locomotion 路径剩余长度——Brain 经黑板键 path_remaining 读，T14 写；缺键用
   body 距 patrol_target 距离）且 最近已知敌对距离 > KNIFE_SAFE_DIST（perception
   last_known_pos 全体目标最小距离）→ switch_intent(2)；最近敌对进入 KNIFE_SAFE_DIST
   → switch_intent(0)（切回 AK 主枪）。ENGAGE 不切刀。
2. **弹尽切手枪**：state==ENGAGE 且 mag_frac ≤ PISTOL_MAG_THRESHOLD 且（无掩体或
   最近掩体 > COVER_DIST_MAX——掩体 = 黑板 cover_target 有效或 T14 重选判定）→
   switch_intent(1)；有掩体 → RELOAD 路径（T13 已接：mag_frac<0.3 → RELOAD——
   本任务细化为 ≤0.2 且无掩体走手枪，注释衔接）；glock_frac==0 → 强制 RELOAD
   （switch_intent 不发）。
3. **集群扔雷**：state ∈ {ENGAGE, ALERT} 且 ≥2 敌对已知位置（视线可见 + LKP）间
   水平距 < GRENADE_CLUSTER_DIST 且质心距 body ≤ GRENADE_RANGE 且 grenade_left>0 →
   throw_intent(质心) + 黑板 intent_throw_pos；扔雷后（信号发后 2s 或黑板 grenade_left
   递减——M3.3 黑板记录 grenade_left 减一语义 + weapon_slot 回 0 意图）切回主枪。
   Hunter 策略突入前（strategy.params().type=="hunter" 且 grenade_open）→ 朝
   centroid 25m 内 LKP 扔雷开路（同雷程门控）——策略与集群不叠加（Hunter 分支优先）。
4. **近身刀人**：敌对水平距 < MELEE_RANGE（当前目标或任一可见敌对）→
   melee_intent(target) + 黑板 intent_melee_target + switch_intent(2)（切刀语义）。
5. **弹药箱寻路**：reserve==0 或 grenade_left==0 → 最近弹药箱点（
   `LAYOUT.ammo_box_points()` 位置表——10 点预置）→ locomotion.set_target(点) +
   黑板 ammo_box_target；到达（arrived 且 ammo_box_target 非空）→ 清 ammo_box_target
   （M3.4 接线拾取）。ENGAGE 中不寻路弹药箱（保战斗优先），RETREAT 中允许。
6. **幂等**：发前比较黑板 intent_switch/intent_throw_pos/intent_melee_target 与
   新意图，相同不发；状态转移清空过期意图键。
7. T13/T14 已实现部分不动；本任务只加武器决策分支（tick 内独立守卫，按状态门控）。
