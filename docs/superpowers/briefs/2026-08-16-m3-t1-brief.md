## 测试规格（test/unit/test_enemy_command_drive.gd，TDD RED 先行）

装配范式：`test/unit/test_auto_command.gd` 同款——`Enemy.new()` + add_child 入树 +
`_make_box(Vector3(40,1,40), Vector3(0,-0.5,0))` 地面（StaticBody layer 1，顶面 y=0）+
真实物理帧推进（`await wait_physics_frames(n)`）。Enemy 落定后（~25 帧）再开始相位推进。
Enemy 的 command_override 在 _ready 恒设——直接取 `enemy.command_override` 引用使用。

1. `test_bot_move_axis_forward`：落定后 cmd.move_axis=(0,1) 60 帧 → -Z 位移 > 0.5，
   X 位移绝对值 < 0.2（rotation.y=0 时前进=-Z）
2. `test_bot_move_follows_yaw`：`enemy.rotation.y = PI/2` 后 cmd.move_axis=(0,1) 60 帧 →
   +X 位移 > 0.5（本地轴随朝向旋转）
3. `test_bot_jump_edge_consumed`：落定后 `cmd.jump_pressed = true` → 推进 ≤90 帧：
   断言 ①下一物理帧后 `cmd.jump_pressed == false`（读取即清零的单帧边沿语义）
   ②期间 enemy.global_position.y 上升超过落定 y + 0.5（真实起跳离地——非模拟）
4. `test_bot_crouch_reserved_false`：crouch 恒 false 全程 → 前进位移与测试 1 同量级
   （> 0.5m），且无异常速度特征（水平速度量级 ≤ 6.35×1.2 容差可省略——不断言精确值，
   仅断言位移同量级证明 crouch=false 不干扰移动）
