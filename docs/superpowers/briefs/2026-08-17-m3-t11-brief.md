```gdscript
# 新增 static 纯函数（方向翻转参数计算，可单测）：
static func directed_edge_params(edge: Dictionary, forward: bool) -> Dictionary
# 输入：数据集边条目（edges 数组元素，含 delta_h/human/physics/link_names 等）
#       forward = 路径穿越方向与链接注册正向一致（水平点积 ≥0）

#   1) 段方向判定：dir = (seg.to - seg.from) 水平投影与注册正向
#      (link.to - link.from) 水平投影点积 < 0 → 反向
#   2) 参数消费改 directed_edge_params(edge, forward) 输出（替代原样读
#      edge["delta_h"]/human.p50——原逻辑即 T5 疑虑 1③ 缺陷）
#   3) 触发速度门动态值 = max(pick_jump_speed(directed.delta_h, dist,
#      directed.human_p50, directed.augmented, directed.v_req), RUNUP_GATE_SPEED)
#      （反向时 pick 走 v_req×1.15 档——已含）

# 触发位置约束（T5 疑虑 1②）：
#   TRIGGER 允许触发增加起飞位置窗：起跳点水平投影必须落在数据集边
#   takeoff_zone（center/size，膨胀 0.5）内；反向穿越时 takeoff 侧 = 注册 to 侧
#   （方向感知取 zone：forward → takeoff_zone；反向 → landing_zone 作为起飞区，
#    对应 landing 判定用另一侧）；无数据集条目 → 回退位置距 seg.from 水平距
#   ≤ JUMP_ARRIVE(0.8) 圆盘（T3 原口径）
#   实现：抽 static 纯判定 func trigger_zone_ok(edge: Dictionary, forward: bool,
#       body_pos: Vector3, seg_from: Vector3) -> bool

# landing_zone 方向感知（T5 疑虑 1①）：

#   （seg.to.y − closest(落点).y ≤ HEIGHT_GATE——T3 修复轮 2）；无数据集条目 →
#   回退 LAND_TOLERANCE 1.5 水平距（T3 原口径）
```

## 语义规格

1. `directed_edge_params` 纯函数如上；反向判定阈值：点积 < 0（含 0 即正向——正交
   无位移差，保持正向口径）。
2. `_enter_jump` 消费全部改经 directed 参数（禁止再直读 edge["delta_h"] /
   edge["human"]["takeoff_speed"]["p50"]——原直读点即缺陷本体）。
3. 触发位置窗在 TRIGGER 速度门/方向锥判定**之后**追加（速度+锥+位置三条件全满足
   才 jump_pressed）；zone 判定失败不触发、不进入 AIR、不计数失败（继续 RUNUP 调整
   位置，超 TRIGGER_TIMEOUT 回 RUNUP——T3 既有语义）。
4. `_landed_ok` 水平判定改方向感知 zone（膨胀 0.5）优先，无条目回退 LAND_TOLERANCE；
   竖向 navmesh 双锚口径不变。
5. **回归锚**：T5 冒烟（TowerToLongWall_W 反向）修复后参数正确（不再靠 LAND_TOLERANCE
   侥幸——测试 5 断言）；T3 正向跳不受影响（测试 6 断言）。
