## 接口块（精确签名，照抄）

```gdscript
# bot_perception.gd 扩展：
const LKP_TTL := 8.0      # s：LKP 记忆时长（不可见后遗忘）
signal lkp_updated(target: Node, pos: Vector3, visible: bool)

var _lkp: Dictionary = {}     # target(Node) -> {pos: Vector3, invisible_t: float}

func last_known_pos(target: Node) -> Vector3   # 查询（无条目返回 Vector3.ZERO）
func invisible_time(target: Node) -> float     # 不可见累计（s；无条目返回 -1）
```

## 语义规格

1. 目标可见（T6 hostile_visible 发射时）：`_lkp[target] = {pos=发射位置, invisible_t: 0}`
   + `lkp_updated(target, pos, true)`。
2. 目标不可见（T6 hostile_lost 发射时起）：invisible_t 每 tick 累计（delta）；超
   LKP_TTL → 条目删除 + `lkp_updated(target, Vector3.ZERO, false)`。
3. 目标死亡/无效（is_instance_valid false 或 Enemy.dead）→ 条目即时删除（不报信号）。
4. 位置仅存最后可见位置；不可见期间位置冻结。
5. T6 的 `_visible` 集合与 `_lkp` 联动：lost 时保留 `_lkp` 条目仅计时，visible 复现时
   invisible_t 清零刷新位置。
