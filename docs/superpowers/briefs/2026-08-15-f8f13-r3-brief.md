## 重点风险清单（逐项核实）

1. F10 预检位置：`_speed_gate_relaxed` 计算块之后、`_air_t = 0.0` 之前（F12 检测块
   的相对位置）；预检 return 时 `_state` 未切 JUMP → 状态机落回 WALK 的安全语义
2. F10 的 `_replan_from_current()` 调用与 T4 即将实施的 `_try_replan_from_current()`
   的关系：T4 简报调用点 3 会替换此处——现状 `_replan_from_current` 直调 + 
   `_anchor_fallback_done` 守卫与 T4 规格兼容（记录确认即可）
3. F-degen 阈值 0.3 与 `_speed_gate_relaxed` 1.2 的关系：degenerate 是 relaxed 的
   子集（0.3 < 1.2）——两标志并存语义（relaxed 用 0.6v 门、degenerate 追加近静止
   放行）；正常跳跃（锚点 >1.2m）两者皆 false
4. 圆盘触发条件链：`to_h.length() <= 0.6 and height_ok and not _wall_ahead(1.0)` +
   `_try_trigger(gate, true, _runup_degenerate)`——degenerate 时近静止放行仅作用于
   圆盘路径，墙探（false）与停摆（true）不受影响
5. 测试 12 白盒锚：构造跳段的真实性（CrateToCluster_WS 段 + 玩家箱底位置——
   预检真的触发）；call2 的同段复用（`_anchor_fallback_done` 已 true 分支）
6. 测试 13 断点校准：35*60 与实测 1933 帧的余量（~2.8s）——评估该余量是否会
   因机器性能/物理帧抖动而 flake（给出你的判断，Minor 级风险记录即可）
7. 测试 13 的 4 次 Crate_WS 起跳 + 压墙 5s 卡死重寻路（~13s）——既有行为非本轮
   引入，确认非 F-degen 误伤（degenerate 判定只在 CrateToCluster 锚点坍缩时触发）
