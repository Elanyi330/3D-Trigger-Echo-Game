## 接口块（精确签名，照抄）

```gdscript
# Levels/M2_TDM/bot_locomotion.gd
class_name BotLocomotion
extends Node

signal arrived                    # 到达目标（决策层 M3.3 消费；M3.1 仅冒烟断言）
signal jump_failed(link_name: String)  # 跳跃失败（T3 起发出；本任务仅声明不发出）

const ARRIVE_RADIUS := 0.8        # 到达半径（水平距）
const HEIGHT_GATE := 0.72         # 途经点高差门（> 此值 → 重寻路一次 / T3 接管跳跃执行）
const SIMPLIFY_STEP := 1.0        # 途经点简化：1.0m 稠密点
const SIMPLIFY_DY := 0.2          # 途经点简化：0.2 高差保留
const LOOKAHEAD_DIST := 1.5       # 前瞻转向距离（当前点距 body < 此值 → 转向基准取下一途经点）

var body: CharacterBody3D         # Enemy（读 global_position / rotation.y）
var map_rid: RID                  # 导航地图 RID
var command: MovementCommand      # 指向 body.command_override（同引用，勿新建）

func setup(b: CharacterBody3D, m: RID) -> void
func set_target(pos: Vector3) -> void
func clear_target() -> void
func tick(delta: float) -> void

static func simplify_path(points: PackedVector3Array) -> PackedVector3Array
static func approach_point(body_pos: Vector3, body_yaw: float,
        point: Vector3, next_point: Vector3) -> Vector2
static func within_height_gate(body_pos: Vector3, point: Vector3) -> bool
```

## 语义规格

1. **setup**：存 body/map_rid；`command = b.command_override`（Enemy._ready 恒设，T0 已固化）。
2. **set_target**：`NavigationServer3D.map_get_path(map_rid, body.global_position, pos, false)`
   （optimize=false 走廊忠实——遍历器时代教训）→ 丢弃首点（含 body 自身位置）→
   `simplify_path` → 存 `_path`；`_repath_count = 0` 重置。
3. **simplify_path（static 纯函数）**：输出含首尾点；相邻保留点间沿段线性插值补充稠密点
   （间距 ≤ SIMPLIFY_STEP）；任意点间 y 差 ≥ SIMPLIFY_DY 的点必保留（坡道/台阶走面信息不丢）。
   实现建议：先选保留集（首点 + 方向变化拐点 + 高差显著点 + 尾点），再对相邻保留点对插值。
4. **tick（每物理帧由 Enemy._physics_process 或后续 Brain 调用）**：
   - `_path` 空 → `command.move_axis = Vector2.ZERO` → return
   - 当前途经点到达判定：水平距 < ARRIVE_RADIUS → 弹下一途经点；弹空 → `arrived.emit()` +
     `command.move_axis = Vector2.ZERO` → return
   - **高度门**：下一途经点 y − body y > HEIGHT_GATE → `_repath_count < REPATH_LIMIT(=2)` 则
     `set_target(原目标)` 重寻路一次并 return，否则 `clear_target()`（诚实失败——T3 接管跳跃）
   - **前瞻转向**：当前点水平距 body < LOOKAHEAD_DIST 且存在下一途经点 → 转向基准取下一
     途经点（提前转，不绕最小转弯圆——遍历器 fix 8 教训）；否则取当前点
   - 输出：`command.move_axis = approach_point(...)`（y=前后分量）；jump/crouch 不碰
5. **approach_point（static 纯函数）**：body 朝向 yaw → 世界方向 dir = 基准点−body 水平投影 →
   转 body 本地坐标（本地前 = -Z 即 rotation.y 下 (sin yaw, -cos yaw) 旋转）→ 归一化输出
   `Vector2(右分量, 前分量)`。基准点水平距 < 0.01 → 返回 ZERO（防除零）。
6. **within_height_gate（static 纯函数）**：`point.y - body_pos.y <= HEIGHT_GATE`。
7. **T0 移交注记（注释固化，勿改行为）**：bot 的 step-up 查询掩码为 1（Enemy._ready 中
   super 先于 mask=3 赋值执行，T0 审查遗留）——语义上有意设计：**bot 登台探针不含 Player
   层，不把玩家当地形**。在 setup 注释中记录此约定。

## 测试规格（test/unit/test_bot_locomotion_path.gd，TDD RED 先行）

1. `test_simplify_keeps_corners`：L 形路径（如 (0,0,0)→(5,0,0)→(5,0,5)）→ 简化后保留拐点
   (5,0,0) 在输出序列中

3. `test_simplify_keeps_dy`：平路 + 一点 y 高 0.3 → 该高差点保留
4. `test_approach_toward_point`：yaw=0、基准点在 -Z → 输出 ≈ (0, 1)（前分量 1，右分量 0）
5. `test_approach_lookahead`：当前点近（水平距 <1.5）+ next_point 在侧面 → 输出含侧向分量
