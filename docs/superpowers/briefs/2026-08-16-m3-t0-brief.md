## 语义规格

1. **Enemy.tscn**：根节点 type `StaticBody3D` → `CharacterBody3D`；新增子节点
   `CollisionShape3D`（CapsuleShape3D：radius 0.31 / height 1.54 / position (0, 0.92, 0)）
   ——形状必须 scene 声明（MovementController 的 `@onready _col_cached` 在树进入时查找，
   代码内 _ready 创建会错过缓存窗口）。
2. **Enemy.gd**：`extends MovementController`（class_name 全局可见）。_ready 顺序：
   `super._ready()` → 碰撞层/掩码/command_override → 视觉 tint/标签/HeadHitbox/随机武器
   （既有逻辑不动，仅删除 body_shape 创建块）。
3. **玩家侧**：`Player/MovementController.tscn` 的 collision_mask 3 → **7**（1|2|4）。
4. **武器命中侧** mask 1 → **5**（1|4），注释同步：
   - `WeaponCore.gd:257` `query.collision_mask = 1` → `5`
   - `MeleeController.gd:148` `params.collision_mask = 1` → `5`
   - `Grenade.gd:79` `collision_mask = 1` → `5`、`:102` `query.collision_mask = 1` → `5`、
     `:149` `pq.collision_mask = 1` → `5`
5. **torso 组语义不变**：MovementController step-up 查询过滤 torso/head 组（既有）——bot 在
   torso 组 → 玩家登台查询继续忽略 bot；玩家对 bot 的阻挡由 move_and_slide 掩码 7 提供。
6. 死亡帧 `velocity = Vector3.ZERO`（防尸体被残余速度推离倒地点）。
