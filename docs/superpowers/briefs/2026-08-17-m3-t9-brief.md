## 接口块（精确签名，照抄）

```gdscript
# Levels/M2_TDM/event_board.gd
class_name EventBoard
extends Node

signal death_event(faction: String, pos: Vector3, t: float)

const DEATH_TTL := 30.0     # s：死亡事件保留

var _deaths: Array = []     # [{faction, pos, t}]

func record_death(faction: String, pos: Vector3) -> void
func recent_deaths(faction: String, within: float) -> Array   # 时间窗查询（策略层 M3.3 消费）
func tick(delta: float) -> void    # TTL 剔除（每物理帧）
```

## 语义规格

1. `record_death`：追加 {faction, pos, t=_elapsed}（`_elapsed += delta` 于 tick 首行）。
2. `recent_deaths(faction, within)`：返回 faction 的 `_elapsed - t <= within` 事件列表
   （副本，按 t 升序）。
3. `tick`：`_elapsed - t > DEATH_TTL` 剔除。
4. 全局单板（L_M2 持有一个），faction 字段区分阵营——两阵营 bot 都读（M3.3 装配）。
5. **L_M2 最小侵入接线**：
   - `_ready`（`_setup_tdm` 前或后均可）：`_board = EventBoard.new()`、`_board.name =
     "EventBoard"`、`add_child(_board)`；`_board.tick(delta)` 在 `_process(delta)` 首行调用
   - `_on_enemy_died(e)` 现有函数内**追加一行**：`_board.record_death("enemy",
     e.global_position)`（其余逻辑不动）
   - `_on_player_died()` 现有函数内**追加一行**：`_board.record_death("friendly",
     _player.global_position)`
   - 不做其它改动；既有 407+ 测试零回归。
