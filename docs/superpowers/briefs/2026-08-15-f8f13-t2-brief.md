## 规格

### 常量与状态（auto_traversal.gd）

常量区（紧跟 `RUNUP_TURN_GATE` 后）：

```gdscript
const VERTICAL_LINK_DIST := 0.05  # snap 后 from/to 水平距 < 此值 = 垂直链接（F12 原地直上跳）
```

状态区（`_speed_gate_relaxed` 声明附近，同风格注释）：

```gdscript
var _vertical_jump := false  # 当前跳跃为垂直链接模式（F12）：AIR 零水平输入、停摆唯一触发
```

### F12 检测（_enter_jump）

1. 函数开头（`_jump_seg = seg` 之后）重置：`_vertical_jump = false`
2. 在 `_to_point` 的 zone 重瞄准块**之后**（即 `_travel_dir` 计算之前）判定：

```gdscript
	# F12 垂直链接检测：snap 后 from/to 水平距 < VERTICAL_LINK_DIST（Crate_WN/WS/ES/EN
	# 类「原地直上箱顶」链接——travel_dir 为零向量，方向语义不存在；执行改垂直模式）
	_vertical_jump = Vector2(_to_point.x - _from_point.x,
			_to_point.z - _from_point.z).length() < VERTICAL_LINK_DIST
```

注：垂直链接 dist 0 不会进入 zone 重瞄准分支（短跳守卫 <1.2m），但以最终 `_to_point` 口径
判定最稳。`_jump_v = pick_jump_speed(delta_h, 0, …)` 与 `_travel_dir = ZERO` 为既有口径，
不改。

### F12 触发路径（_runup_tick）

1. 墙探预跳块加垂直豁免（`_travel_dir` 为零向量时 `_wall_ahead` 射线退化，语义上垂直跳
   只走停摆路径）：

```gdscript
	if not _vertical_jump and _try_trigger(gate_speed, true, false) and _wall_ahead():
		_trigger_jump()
		return
```

2. 停摆路径（`is_on_wall and along <= STALL_TRIGGER_ALONG and _runup_t >= 0.5`）**不动**——
   T1 已把该路径改为 `_try_trigger(gate_speed, true, true)`，近静止放行 → 贴箱停摆即直上跳，
   这是垂直模式的唯一有效触发。
3. 圆盘路径（`to_h.length() <= 0.6 and height_ok and not _wall_ahead(1.0)`）**不动**——T1 已改
   `_try_trigger(gate_speed, true, false)`，近静止不放行 → 垂直模式下圆盘天然不触发。

### F12 空中（_air_tick）

```gdscript
	_steer_toward(_to_point, delta)
	_cmd.move_axis = Vector2.ZERO if _vertical_jump else Vector2(0, 1)
```

（替换原 `_cmd.move_axis = Vector2(0, 1)` 行——零水平输入 → 无 REST 漂移 → 纯弹道落回箱顶；
`_steer_toward` 对零方向向量返回 true 不转，不动。）

### F11 压墙恢复（_runup_tick）

1. **函数开头**（8s 超时检查之后、其余逻辑之前）加：

```gdscript
	# F11 压墙恢复：0.5s 压墙锁存 _wall_follow 后不走滑墙、直接 recover 回锚点重跑
	# （≤3 次有界，_teleport_to 自带 _reset_wall_state 清锁存）——助跑楔墙冻结
	# （EastSpurN「助跑卡死」：轨道漂移进墙角全速压墙位移 0）的有界化根治
	if _wall_follow:
		_recover_runup()
		return
```

2. **停摆检查之后**（圆盘检查之前）追加压墙检测（传实际施加指令——与 TO_ANCHOR F7-3 同口径）：

```gdscript
	# F11 压墙检测放停摆之后：起跳点贴墙是设计内停摆跳（沿 ≤0.8 + on_wall 先行触发），
	# 不能被压墙 recover 抢走；只有停摆不满足（跑道中段障碍楔死）才落压墙 → recover
	_wall_press_detect(Vector2(_cmd.move_axis.x, _cmd.move_axis.y).length(), delta)
```

顺序约束必须保持：停摆检查 → 压墙检测 → 圆盘检查。`_recover_runup`/`_wall_press_detect`/
`_reset_wall_state` 均为既有函数，不改其实现。

## 上下文要点（从根因分析提取）

- RC-2 子集（垂直链接）：Crate_WN 链 6 面失败——from/to 同点 → travel_dir=0 → 残余动量
  方向=落点方向（45° 漂移）→ 飞离 1×1 箱顶。F12 把该场景改为「贴箱停摆 → 直上跳 →
  零水平输入纯弹道」，落点=起跳点 xz（胶囊压箱侧 0.5m，中心落箱矩形内）
- RC-4：EastSpurN/WestSpurS「助跑卡死」= 轨道漂移进墙角全速压墙冻结（hspeed 5.45 位移 0），
  RUNUP 无压墙检测。F8 已消除轨道漂移，剩余场景=跑道障碍楔死 → F11 压墙 recover 有界化
- 停摆 vs 压墙 recover 的竞争：停摆先行（设计内贴墙跳），压墙 recover 兜底（楔死）
