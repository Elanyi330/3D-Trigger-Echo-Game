```gdscript
# Levels/M2_TDM/tactical_points.gd
class_name TacticalPoints
extends RefCounted

const TIER_WEIGHT := {"simple": 1.0, "medium": 0.7, "hard": 0.35, "extreme": 0.15}
# 面级分析报告 tier 映射：简单→simple / 中等→medium / 困难→hard / 高难→extreme
```

## 语义规格

1. **tier 快照表**（内嵌 const，注释注明快照日期与来源）：160 面名 → tier 从
   `docs/reports/2026-08-16-face-analysis.md` 分档清单提取（简单 137/中等 13/困难 4/
   高难 6 面名列表）；**导航不可达面直接排除**（不进入 _points——报告清单中标注
   「导航不可达」的条目：BackN_LOS_E/W、BeltN_Box1/2、CampN_* 系列、CornerNE_Box1、
   Pillar_SW、UmbrellaW、WallNorth 等——以报告 §2 全部「导航不可达」标注为准逐条
   提取，测试 1 断定点数 = 160 − N 必须与报告一致）。快照表在 `_POINTS` 常量字典：
   {face_name: tier}（实现者从报告逐条抄录，不可遗漏不可多录——测试 1 钉死总数）。
2. **build_from_faces**：`JumpEdges.faces()` 每面（含 center/top_y 字段——先读 faces()
   输出确认字段名）→ 查快照表 → 建点 {face, center, tier, weight=TIER_WEIGHT[tier]}。
   快照表未含面名（报告后新增）→ 默认 "simple" + 注释警告（数据债务注记）。
3. **score**：`weight / (1.0 + dist * 0.1)`——权重仅影响同等成本比较（设计 §三 3）；
   dist=水平距。
4. **weighted_pick**：候选 = 距 pos 水平距 ≥8m 的点（避免原地）；score 排序取最高；
   rng_seed=0 真随机（同分随机）、>0 确定性（同分取 seed 排序最小名——实现者定
   确定性平局规则并注释）。
5. **nearest**：距 pos 最近且 tier 序 ≤ tier_max 的点；返回 {face, center, tier,
   weight, dist}；无合规点 → 空字典 {}。

1. `test_build_counts`：build_from_faces(JumpEdges.faces()) → 点数 == 160 − N
   （N = 报告「导航不可达」面数，实现者从报告统计并注释；断言用该值）
2. `test_tier_weights`：四档权重映射（1.0/0.7/0.35/0.15）；导航不可达面不在点集
   （抽名断言：BackN_LOS_E 等不可达名查无）
3. `test_weighted_pick_seed_deterministic`：同 seed 同 pos 两次 pick 相同面名
4. `test_score_prefers_near_easy`：score(1.0, 5) > score(0.7, 5) 且 score(0.7, 1) >
   score(1.0, 40)（构造数值断言排序语义——权重与距离的权衡方向）
5. `test_nearest_tier_filter`：构造小点集（近 hard 点 vs 远 simple 点）→
   nearest(pos, "medium") 返回远 simple 点（tier 过滤优先于距离）
