## 语义规格

1. **PATROL**：进入 PATROL 时选点 `tactical.weighted_pick(body.global_position)`
   （T12 函数；策略偏置 T15 接入点留注释）→ locomotion.set_target(center) →
   黑板 patrol_target。到达（locomotion.arrived）→ `_post_hold_t = randf_range(2,4)`
   驻点倒计时 → 归零换点（再 weighted_pick，排除当前点：实现为二次 pick 或
   距离过滤 ≥8m——weighted_pick 已有 ≥8m 候选过滤，直接重 pick 即可）。
2. **ALERT**：进入时记 `_alert_pos`（黑板 alert_pos 读）→ set_target(alert_pos) →
   黑板 target_lkp。到达后 `_alert_t` 累计，超 ALERT_NO_FIND 且无新事件 → PATROL。
   新 heard_event 在 ALERT 中 → 刷新 _alert_pos + 重 set_target + _alert_t 清零。
3. **CHASE**：目标 = current_target（视线丢失后的 LKP）——每 tick 读
   perception.last_known_pos(current_target) → 若 LKP 有效（非 ZERO）且与上次
   不同 >0.5m → set_target 刷新；`_chase_distance` 累计（自 _chase_origin 起 body
   实际移动距离——body.global_position 每帧位移和）。LKP 过期（last_known_pos
   ZERO）或 `_chase_distance > CHASE_LIMIT` → ALERT（chase_origin 清空）。
   视线内再发现 → ENGAGE（T13 已接）。
4. **ENGAGE 掩体重选**：`_cover_t` 累计，归零时（周期 randf_range(3,6)）评估——
   候选 = tactical._points 中距敌（current_target/LKP）水平距 ∈ [COVER_MIN,
   COVER_MAX] 且 tier 序 ≤ COVER_TIER_MAX 且对敌有 LOS 断点（复用
   BotPerception.los_blocked 静态：空间 ray 掩码 5，从掩体点胸口高度射向敌胸口
   ——被挡 = 有断点）→ 取最近 → set_target + 黑板 cover_target；无候选 → 保持
   原位（_cover_target 清空）。ENGAGE 退出时 cover 状态清理。
5. **目标选择**：接敌时（hostile_visible）current_target = 最近可见敌对
   （多目标取 body 距离最近）；目标死亡（died 信号或 is_instance_valid false 或
   Enemy.dead）→ current_target 清空 → PATROL。
6. T13 已实现部分不动；本任务仅填 T14 状态行为（PATROL/ALERT/CHASE 细化 +
   ENGAGE 掩体）+ 目标管理。
