## 二、M3 目标与范围

**目标**：让敌方 bot（5 人波次）具备「能用、不蠢」的基础战斗 AI——能在地图内自主
寻路移动、感知玩家、交火、简单走位；为 M4（进阶决策/战术）打底。

**范围**：
- ✅ bot 移动子系统：navmesh 路径跟随 + 跳跃链接**一次参数化执行**（无试错无重试）
- ✅ 感知子系统：视线（LOS）+ 听觉事件（枪声/脚步），与决策层分离
- ✅ 决策子系统：分层状态机（idle/巡逻/警戒/接敌/追击/换弹/撤退）+ 掩体选择雏形
- ✅ 战斗：射击（复用武器系统）、走位（对抗式简单规避）、死亡/重生集成
- ❌ 团队协同/战术包夹/经济决策/难度曲线 → M4
- ❌ 玩家同款完整行为（扔雷/近战决策）→ M4（本子内 bot 只开枪）

## 三、架构（三层分离，企划书约定 + 调研共识）

```
┌─ 决策层 BotBrain（行为树/HSM）——目标选择/状态转移/参数决策
│   输入：黑板（感知事件 + 战术点库 + 自身状态）
│   输出：MovementCommand（移动意图 + 跳跃意图）+ 射击意图
├─ 感知层 BotPerception——视线 raycast（分段+遮蔽判定）/听觉事件队列/威胁记忆
│   事件通过信号/黑板上报，禁止内嵌状态机（企划书铁律）
└─ 移动层 BotLocomotion——navmesh 路径跟随 + 跳跃链接参数化执行 + 朝向控制
    复用 MovementController 物理模型（同 CS 手感数值），命令接口 = MovementCommand
    （与遍历器解耦保留的输入抽象——M3 起唯一消费者）
```

**关键设计决策（调研落地）**：
1. **跳跃=链接参数化执行，永不试错**（UE/Unity/CS2 共识）：路径含跳跃链接段 → 到
   达链接起点 → 以 `pick_jump_speed(delta_h, dist, human_p50)` 一次计算 v → 直线助跑
   触发 → 落地继续。失败（落错面）= 事件上报决策层（换路/换目标），**无重试循环**。
   遍历器时代总结的执行层参数（转向门/方向锥/触发盘/踢面正压）按需移植进
   BotLocomotion（作为被验证过的物理对策，不是照搬状态机）。
2. **路径成本加权**：跳跃链接 cost = 2-5× 行走段（Unity OffMeshLink Cost Modifier
   推荐区间）——bot 默认走地面，跳跃只在捷径收益显著时选择；与人类 CS 手感一致
   （极少跳）。
3. **难度分级消费**（面级分析报告）：决策层目标选择时按 tier 加权——
   简单×1.0 / 中等×0.7 / 困难×0.35 / 高难×0.15；「导航不可达」面直接排除。
   射击掩体选择同理偏好低难度面。
4. **战术点库**（CS2 nav 属性同款）：M3 首版从面表派生——面中心+朝向+难度 tier 即
   战术点；M4 再演进为专门标注（掩体点/交火点/狙击位）。

## 四、子系统规格

### 4.1 BotLocomotion（移动层）

- **输入**：`MovementCommand`（move_axis/jump_pressed/look_yaw——复用现有接口，
  MovementController 物理零改动；bot 使用独立 MovementController 实例 + 无武器时
  speed_modifier 1.0，持枪时同玩家）
- **路径跟随**：`map_get_path(optimize=false)`（走廊忠实，遍历器时代教训）+
  途经点简化（1.0m 稠密点 + 0.2 高差保留——已验证参数）+ 前瞻转向（可攀点视下段，
  遍历器 fix 8 教训）+ 到达半径 0.8 + 高度门
- **跳跃执行**（一次参数化，无重试）：
  - 段分类沿用 classify_segments（link 端点匹配）
  - 参数：`pick_jump_speed(delta_h, dist, human_p50)`（human p50 优先=真实人类值，
    含旋转增强标记数据；钳求解器可行带——已验证函数）
  - 执行：直线助跑（转向门 0.3rad）→ 触发（速度门+方向锥 ±25°）→ 空中微调 → 落地
  - 失败处理：落错面/超时 → 决策层收 `jump_failed` 事件 → 重新寻路（该链接临时
    加权惩罚）或换目标；**无重试无传送**
- **卡顿对策**（遍历器时代全部病理的教训清单，逐项移植）：
  滑墙（压墙 0.5s → 切线滑移 2s，手性锁存每 episode 清零）；踢面正压转向（碰撞法向
  朝玩家侧，pos−cn 恒在墙内）；可攀面（0<高差≤0.62）不滑墙压入直走；锚点可达性
  预检（>0.72 面高差 → 重寻路）；退化跑道（<0.6m）圆盘近静止放行；WALK 途经点 8s
  进展超时 + 重寻路上限 2；卡死 5s/0.3m 兜底
- **路径规划失败**（no_path）→ 决策层事件（目标不可达 → 换战术点）

### 4.2 BotPerception（感知层）

- **视线**：头部起止 raycast（物理层同玩家命中口径）+ 分段采样（防穿缝误判）+
  视锥角（~120°）+ 视距（~40m，背街 LOS 板设计的对抗距离）
- **听觉**：枪声事件（声源+武器口径映射噪音半径）/脚步事件（距离相关）；事件带
  时间戳衰减（记忆遗忘）——黑板消费，感知不决策
- **威胁记忆**：最后已知位置（LKP）+ 不可见计时——追丢后进「警戒-搜索」而非回 idle
- 敌人互见处理：bot 对 bot 不感知（M3 只对玩家）——波次为 5 敌 vs 玩家+4 友军，
  友军为无脑陪跑（沿用 M2 波次行为），M3 升级敌方 bot

### 4.3 BotBrain（决策层，分层状态机）

- **状态**：IDLE（出生点待机）→ PATROL（无目标时沿战术点巡逻/驻点）→ ALERT
  （听觉事件 → 转向警戒/前往 LKP）→ ENGAGE（视线内 → 交火：移动中射击/短点射/
  换弹时机）→ CHASE（失视 → 追击 LKP）→ RETREAT（低血量/弹尽 → 撤退换位）
- **目标选择**：战术点库 + 难度权重 + 距离成本；接敌后目标=玩家 LKP
- **掩体雏形**：ENGAGE 中周期性重选点位（距离 8-15m、难度≤中等、有 LOS 断点）
- **参数**：反应时间 0.3-0.6s（看到→开枪延迟，人类感）、射击精度分层（M4 调难度）、
  追击距离上限（防拖出波次区域）

### 4.4 数据消费口径（拍板哲学固化）

- 跳跃参数：真实人类 p50（climb 样本）→ 无真实 → 增强（标记，置信折扣 0.9）→ 无 →
  求解器 v_req×1.15
- 面难度：分析报告 tier 表（docs/reports/2026-08-16-face-analysis.md）→ 决策权重；
  报告由 tools/analyze_faces.py 随语料增长重跑（3000 上限内）
- 语料持续增长：玩家游玩自动记录（3000 FIFO）→ 数据集重建管线按需重跑

## 五、实现过程计划（SDD，沿用项目惯例）

| 阶段 | 内容 | 产出/验收 |
|------|------|-----------|
| M3.1 移动层 | BotLocomotion（路径跟随+跳跃参数化执行+卡顿对策移植）+ MovementCommand 复用验证 | 单测：跟随/跳跃执行一次成功/失败事件/卡顿兜底各锚；冒烟：bot 从出生点走到塔顶（链接链） |
| M3.2 感知层 | BotPerception（LOS/听觉/记忆）+ 黑板 | 单测：遮蔽判定/视锥/事件衰减锚；集成：玩家出现→ALERT |
| M3.3 决策层 | BotBrain HSM 七状态 + 战术点库（面表派生）+ 难度权重 | 状态转移表测试；行为冒烟：5 bot 波次全流程 |
| M3.4 战斗集成 | 射击（散布/命中同玩家口径）+ 掩体重选 + 死亡/重生（波次框架接入） | 实战冒烟：首交火时间、bot 击杀率、无挂死；用户实机验收 |
| M3.5 收尾 | 难度参数化（.tres 配置）+ 文档同步 | GUT 全绿 + 用户 playtest |

**TDD 贯穿**：每任务先失败测试后实现；**审查贯穿**：每任务独立审查者。
**验收判据**：bot 能自主完成「出生 → 寻路跨链接 → 接敌 → 交火 → 被击杀/重生」完整
闭环；无卡死/无穿墙/无掉落循环；首交火 ≤ 8s；GUT 全绿。

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 跳跃参数化执行在真实对局（压力下）失败率高于遍历验证 | 失败事件→重寻路兜底（无重试设计）；M3.4 实战冒烟统计失败率，超阈值回滚到「不跳只走」保守模式 |
| bot 数量 × 感知 raycast 性能 | 感知节流（0.2s 间隔）+ 视锥/视距裁剪；5 bot 预算内实测帧率 |
| 波次与 bot AI 框架耦合 | 波次只负责出生/计数；AI 生命周期独立（死亡→Brain 状态机重置） |
| 难度权重过强导致 bot 回避整个区域 | 权重仅影响「同等成本比较」，不硬禁（除导航不可达）；M3.4 实测分布 |
