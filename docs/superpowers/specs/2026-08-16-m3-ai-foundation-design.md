## 二、M3 目标与范围

**目标**：让全部 9 个 bot（5 敌 + 4 友军）具备「能用、不蠢」的基础战斗 AI——自主
寻路移动、感知敌对阵营、交火、武器自主决策、简单走位与策略；为 M4（团队协同/
战术/人格/难度曲线）打底。

**范围**：
- ✅ bot 移动子系统：navmesh 路径跟随 + 跳跃链接**一次参数化执行**（无试错无重试）
- ✅ 感知子系统：视线（LOS）+ 听觉事件（枪声/脚步）+ 威胁记忆（LKP），与决策层分离
- ✅ 决策子系统：分层状态机（七状态）+ 策略选择器（4 策略目录）+ 掩体雏形
- ✅ 武器自主决策：赶路切刀 / 弹尽切手枪 / 集群扔雷 / 近身刀人 / 弹药箱拾取
- ✅ 战斗：射击（复用武器系统，准头基线 ~35%）、近战、手雷投掷、走位
- ✅ 友军 AI（同 Brain 同参数）+ 友军复活（北营补位器）+ 击杀归因双向
- ✅ 死亡/重生集成：现行 TDM 框架（TdmRespawner 补位；补位=全新节点实例 → Brain
  状态机零状态自然重置，无手动清理）
- ❌ 团队协同/战术包夹/bot 间通信/人格参数/三档难度曲线 → M4
- ❌ 脚步声/枪声真实音频播放 → M6（M3 听觉=数据事件，无音频）

## 三、架构（三层 + 策略上游，企划书约定 + 调研共识）

```
┌─ 决策层 BotBrain
│    ├─ 策略选择器 BotStrategy（场况评估 → 策略生成/裁决/生命周期）→ 策略参数包
│    ├─ HSM 七状态（每个决策点读策略参数包做偏置）
│    └─ 武器决策（切刀/切枪/扔雷/刀人/拾弹药箱）
│    输入：黑板（感知事件 + 战术点库 + 自身状态）+ 事件板（阵营共享）
│    输出：MovementCommand（移动+跳跃意图）+ 射击意图 + 切枪意图
├─ 感知层 BotPerception——视线 raycast（分段+遮蔽判定）/听觉事件队列/威胁记忆
│    事件通过信号/黑板上报，禁止内嵌状态机（企划书铁律）；目标=敌对阵营全体
└─ 移动层 BotLocomotion——navmesh 路径跟随 + 跳跃链接参数化执行 + 朝向控制
     复用 MovementController 物理模型（同 CS 手感数值），命令接口 = MovementCommand
     （与遍历器解耦保留的输入抽象——M3 起唯一消费者）
```

**事件板（EventBoard）**：全局节点（L_M2 装配），存本阵营与敌对阵营共享的战术事件
（死亡事件：阵营+位置+时间戳，TTL 30s）。来源 = L_M2 既有死亡钩子
（`_on_enemy_died` / `_on_player_died` 扩展写板）。**不含击杀者位置**——死亡源头由
各 bot 自己感知推导（拍板：不破坏感知/决策分离，bot 间情报差异天然形成行为差异）。

**bot 形态（实现说明）**：Enemy 类改造——StaticBody3D 静态桩 → CharacterBody3D +
独立 MovementController 实例（玩家同款物理）+ BotBrain/BotPerception/BotLocomotion
子节点。友军共用同一类（`is_enemy=false`）。保留：出生保护 2s/友伤过滤/头顶名/
死亡倒地动画/随机武器视觉（改造为 Brain 自主切枪的视觉载体）。**碰撞层策略**：
bot 新独立物理层（如 layer 4 "Bots"）——bot mask=世界几何（Objects），bot 间互不
碰撞防路径拥堵；玩家 mask 含 Bots（bot 挡玩家路，同现状）；bot 不挡 bot。

**关键设计决策（调研落地）**：
1. **跳跃=链接参数化执行，永不试错**（UE/Unity/CS2 共识）：路径含跳跃链接段 → 到
   达链接起点 → 以 `pick_jump_speed(delta_h, dist, human_p50)` 一次计算 v → 直线助跑
   触发 → 落地继续。失败（落错面）= 事件上报决策层（该链接临时加权惩罚 + 重新寻路）
   或换目标，**无重试循环**。遍历器时代总结的执行层参数（转向门/方向锥/触发盘/踢面
   正压）按需移植进 BotLocomotion（作为被验证过的物理对策，不是照搬状态机）。
2. **路径成本加权**：跳跃链接 cost = 2-5× 行走段（Unity OffMeshLink Cost Modifier
   推荐区间）——bot 默认走地面，跳跃只在捷径收益显著时选择；与人类 CS 手感一致
   （极少跳）。
3. **难度分级消费**（面级分析报告）：决策层目标选择时按 tier 加权——
   简单×1.0 / 中等×0.7 / 困难×0.35 / 高难×0.15；「导航不可达」面直接排除。
   射击掩体选择同理偏好低难度面。权重仅影响同等成本比较，不硬禁（除导航不可达）。
4. **战术点库**（CS2 nav 属性同款）：M3 首版从面表派生——面中心+朝向+难度 tier 即
   战术点；M4 再演进为专门标注（掩体点/交火点/狙击位）。
5. **策略 = 行为偏置参数包**（用户拍板新增）：策略层不新增状态机，只以参数包偏置
   HSM 各决策点（目标选择/路径成本/移动装备/开火节奏/巡逻范围）——与 HSM 正交，
   可独立测试、可扩展目录（M4 团队策略直接往目录加）。

## 四、子系统规格

### 4.1 BotLocomotion（移动层）

- **输入**：`MovementCommand`（move_axis/jump_pressed/look_yaw——复用现有接口，
  MovementController 物理零改动；bot 使用独立 MovementController 实例，移速分档随
  武器自动生效：`speed_modifier = mobility/250`，持刀 1.0 / 手枪 0.96 / 雷 0.98 /
  AK 0.86——现有 WeaponManager._apply_speed_modifier 机制，bot 复用零改动）
- **路径跟随**：`map_get_path(optimize=false)`（走廊忠实，遍历器时代教训）+
  途经点简化（1.0m 稠密点 + 0.2 高差保留——已验证参数）+ 前瞻转向（可攀点视下段，
  遍历器 fix 8 教训）+ 到达半径 0.8 + 高度门
- **跳跃执行**（一次参数化，无重试）：
  - 段分类沿用 classify_segments（link 端点匹配）
  - 参数：`pick_jump_speed(delta_h, dist, human_p50)`（human p50 优先=真实人类值，
    含旋转增强标记数据；钳求解器可行带——已验证函数）
  - 执行：直线助跑（转向门 0.3rad）→ 触发（速度门+方向锥 ±25°）→ 空中微调 → 落地
  - 失败处理：落错面/超时 → 决策层收 `jump_failed` 事件 → 重新寻路（该链接临时
    加权惩罚）或换目标；**无重试无传送**
- **卡顿对策**（遍历器时代全部病理的教训清单，逐项移植）：
  滑墙（压墙 0.5s → 切线滑移 2s，手性锁存每 episode 清零）；踢面正压转向（碰撞法向
  朝玩家侧，pos−cn 恒在墙内）；可攀面（0<高差≤0.62）不滑墙压入直走；锚点可达性
  预检（>0.72 面高差 → 重寻路）；退化跑道（<0.6m）圆盘近静止放行；WALK 途经点 8s
  进展超时 + 重寻路上限 2；卡死 5s/0.3m 兜底
- **路径规划失败**（no_path）→ 决策层事件（目标不可达 → 换战术点）
- **碰撞层**：bot 独立物理层（互不碰撞防拥堵；玩家 mask 含 bot 层保持挡路现状）

### 4.2 BotPerception（感知层）+ 事件板

- **视线**：头部起止 raycast（物理层同玩家命中口径）+ 分段采样（防穿缝误判）+
  视锥角 120° + 视距 40m（背街 LOS 板设计的对抗距离）+ 节流 0.2s
- **目标集**：敌对阵营全体（敌 bot 感知=玩家+4 友军；友军 bot 感知=5 敌）
- **听觉**：敌对枪声事件（声源+武器口径映射噪音半径：AK 大/手枪小/刀静默——具体
  半径值 .tres 参数化）+ 敌对脚步事件（距离相关）；事件带时间戳衰减（记忆遗忘，
  枪声 TTL 3s/脚步 TTL 1.5s）——黑板消费，感知不决策
- **威胁记忆**：最后已知位置（LKP）+ 不可见计时——追丢后进「警戒-搜索」而非回 idle
- **事件板**：死亡事件（阵营+位置+时间戳，TTL 30s）由 L_M2 死亡钩子写入；
  不含击杀者位置（bot 自己感知推导死亡源头）

### 4.3 BotStrategy（策略选择器，新增——用户要求精密设计）

**铁律：直接威胁无条件优先**——视线内敌对出现 → ENGAGE 立即接管，策略只影响
「接敌前的路线、目标与装备选择」。

**目录（4 条，触发条件全部可量化、纯函数、可单测）**：

| 策略 | 触发条件 | 行为偏置 | 生命周期 |
|---|---|---|---|
| 默认 roam | 恒真（兜底） | 无偏置：全图战术点巡逻 | — |
| 猎手 Hunter | 15s 内己方阵亡 ≥2 且阵亡位置质心间最大距离 ≤10m →「阵亡簇」C | 目标选择：C 半径 25m 内敌对目标权重 ×3；前往 C 途中切刀加速，进入 C 30m 切回主枪；**突入前朝 C 区敌方 LKP 扔雷开路**（LKP 在雷程 ≤20m 内）；路径选择沿用侧袭绕行偏置 | 45s，或目标被击杀/目标离开 C 区 >20s → 回默认 |
| 侧袭 Flanker | 目标距 bot 直线 ≥15m 且 navmesh 路径长 > 直线 ×1.5（存在绕行空间） | 路径成本：途经段对目标位置有 LOS 的（采样预检）加权 ×2 → 寻路自然选绕背路线；接敌前持刀贴墙移动 | 一次接敌（进入目标 30m 或开火）即结束 |
| 防守 Hold | 己方存活数 < 敌方存活数 且 15s 内己方阵亡 ≥2 但非簇（簇 → Hunter 优先） | 巡逻范围收缩至己方半场（战术点按 z 过滤）；掩体重选更频繁；优先寻路补弹药箱 | 存活数持平或超时 30s → 回默认 |

**裁决与防振荡**：优先级 Hunter > Flanker > Hold > 默认（.tres 参数可调）；
同阵营同时 ≤2 个 bot 持 Hunter（事件板广播占用，先到先得，后到者选次优）；
同一策略结束后 20s 冷却；策略切换仅在新策略优先级高于当前时发生（防横跳）。

### 4.4 BotBrain（决策层，分层状态机）

- **状态**：IDLE（出生点待机）→ PATROL（无目标时按策略巡逻/驻点）→ ALERT
  （听觉事件 → 转向警戒/前往 LKP）→ ENGAGE（视线内 → 交火：移动中射击/短点射/
  换弹 vs 切手枪决策/近身刀人/集群扔雷/掩体重选）→ CHASE（失视 → 追击 LKP，
  上限 30m）→ RELOAD（换弹/切枪）→ RETREAT（低血量/弹尽 → 撤退换位）
- **目标选择**：战术点库 + 难度权重 + 距离成本；接敌后目标=敌对 LKP；
  受策略参数包偏置（Hunter 簇权重 ×3 等）
- **武器决策规则**（用户拍板，精确触发）：
  - 赶路切刀：目标导航剩余路程 >8m 且最近已知敌对 >15m → 切刀（mobility 250）；
    进入敌对 15m 内 → 切回主枪（AK 优先）
  - 弹尽切手枪：弹匣 ≤20% 且（无掩体或最近掩体 >5m）→ 切 Glock 续战；有掩体 →
    退掩体换弹；Glock 亦空 → 强制换弹
  - 集群扔雷：≥2 敌对已知位置（视线/LKP）间距 <10m → 朝质心投（雷程 ≤20m，
    反向求发射角——ThrowTrajectory 抛物线技术复用）；Hunter 突入开路同此
  - 近身刀人：敌对 <2m → 切刀攻击（复用玩家近战系统：轻击 2.0m/40 伤/连击窗口
    0.8s，重刺 1.6m/65 伤）
  - 弹药箱：备弹 0 或手雷耗尽 → 寻路最近弹药箱（10 固定点预置位置表；拾取复用
    AmmoBox，扩展拾取方支持 bot——现有 `setup(target)` 已接受任意目标）。
    **bot 初始配弹与玩家同口径**（同款有限弹药/手雷初始数，捡箱补弹+新手雷）
- **掩体雏形**：ENGAGE 中周期性重选点位（距敌 8-15m、难度≤中等、有 LOS 断点）；
  Hold 策略下重选更频繁
- **参数**：反应时间 0.3-0.6s（看到→开枪延迟，随机，人类感）、射击准头基线 ~35%
  （瞄准误差参数：目标点高斯偏移+瞄准收敛时间，CS2-Bot-Improver 思路）、短点射
  （AK 3-5 发/组）、追击距离上限 30m（防拖出战斗区）

### 4.5 战斗集成细节

- **击杀归因（双向）**：`take_damage(dmg)` → `take_damage(dmg, attacker)` 签名变更
  （hitscan/近战/爆炸三通道全穿）；敌方死亡 → 击杀者名（友军 bot 或玩家）记入
  TdmStats（名字已全预注册）；玩家死亡 → 归因具体敌 bot 名（原"敌方总分+1"改
  归因）。友伤过滤沿用 `is_friendly_fire` 谓词（bot 以其阵营射击，天然正确）
- **友军复活**：TdmRespawner 复用——北营 10 点补位器（3s 延迟，镜像南营），
  友军 bot 死亡 → 补位全新实例（Brain 零状态重置）
- **准头基线 ~35%**（对静止目标中距离 ~15m）：M3 单档参数，M3.6 进 .tres；
  M4 三档难度在此基础上调
- **bot 与玩家共享弹药箱**（10 箱）：抢补给即游戏性；bot 弹尽/雷尽寻路拾取

### 4.6 数据消费口径（拍板哲学固化）

- 跳跃参数：真实人类 p50（climb 样本）→ 无真实 → 增强（标记，置信折扣 0.9）→ 无 →
  求解器 v_req×1.15
- 面难度：分析报告 tier 表（docs/reports/2026-08-16-face-analysis.md）→ 决策权重；
  报告由 tools/analyze_faces.py 随语料增长重跑（3000 上限内）
- 语料持续增长：玩家游玩自动记录（3000 FIFO）→ 数据集重建管线按需重跑

## 五、实现过程计划（SDD，沿用项目惯例；六阶段）

| 阶段 | 内容 | 产出/验收 |
|------|------|-----------|
| M3.1 移动层 | BotLocomotion（路径跟随+跳跃参数化执行+卡顿对策移植）+ Enemy 类改造（StaticBody→CharacterBody+MovementController+碰撞层）+ MovementCommand 复用验证 | 单测：跟随/跳跃执行一次成功/失败事件/卡顿兜底各锚；冒烟：bot 从出生点走到塔顶（链接链） |

**TDD 贯穿**：每任务先失败测试后实现；**审查贯穿**：每任务独立审查者。

击杀归因无漏记；GUT 全绿；用户实机验收。

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 跳跃参数化执行在真实对局（压力下）失败率高于遍历验证 | 失败事件→重寻路兜底（无重试设计）；M3.4 实战冒烟统计失败率，超阈值回滚到「不跳只走」保守模式 |
| 9 bot × 感知 raycast 性能 | 感知节流 0.2s + 视锥/视距裁剪；9 bot 预算内实测帧率（~45 raycast/s） |
| 策略振荡/过度反应（Hunter 全队倾巢） | 占用上限 ≤2 + 20s 冷却 + 优先级裁决；M3.4 冒烟观察策略分布 |
| 武器切换时机不当（切刀被偷袭/切枪卡节奏） | 阈值参数化 .tres（切刀距离/切枪弹匣线）；playtest 调参 |
| 友军 AI 抢玩家击杀/体验干扰 | 同参数公平 5v5 是设计意图；若 playtest 反馈不佳，M3.6 调友军参数档 |
| 击杀归因三通道改造触及既有伤害结算 | 归因与结算分离（attacker 仅记录不改伤害数值）；既有 369 测试全量回归 |
| 难度权重过强导致 bot 回避整个区域 | 权重仅影响「同等成本比较」，不硬禁（除导航不可达）；M3.4 实测分布 |
