## 〇、根因调查（systematic-debugging 结论）

### 0.1 换弹中切枪（bug：手枪继续换弹动画）

**复现路径**：步枪 RELOADING 中按切枪 → `WeaponManager.switch_to` 无 RELOADING 门控（`WeaponManager.gd:148` 只处理 THROWING）→ 切换成功并 `interrupt_reload()` 旧核心；但 `WeaponView._on_switched`（`WeaponView.gd:147-149`）**不重置 `_reload_t`** → 视图层换弹动画在**新挂载的武器**（手枪）上继续播放完——所见 bug。

**用户要求**：换弹过程中**不允许切换武器**（不是"切枪取消换弹"的 CS 行为，用户明确拍板禁止切换）。

**修复方案**：
1. `switch_to` 增加门控：`if _state == State.RELOADING: return`（位于 THROWING 处理之前、`slot == _current_slot` 检查之后）。换弹中切枪 = 无操作（槽位不变、不发 weapon_switched、换弹继续）。
2. 防御性：`WeaponView._on_switched` 增加 `_reload_t = -1.0` 复位（门控后正常路径不再触发该 bug，但防御未来任何"换弹中挂新武器"路径，成本一行）。

### 0.2 手雷穿地（bug：平台向下投掷穿透地面）

**根因**：`Grenade.gd:_ready` 碰撞球半径 0.1m，RigidBody3D **未开 CCD**（`continuous_cd` 默认 false）。15 m/s 出手 + 平台高度重力加速（3m 下坠触地 ~16.8 m/s）→ 每物理帧位移 ~0.25-0.28m **> 球直径 0.2m** → 离散碰撞检测漏检薄板（平台板 0.4-0.6m/地面）→ 穿透。概率性（与触地相位相关）与用户观察一致。

**修复方案**：`_ready` 增加 `continuous_cd = true`（Godot 内置 CCD 扫掠检测，专治高速小体积隧穿；代价=仅投掷物，性能可忽略）。碰撞半径保持 0.1。

### 0.3 伤害模型现状（回答用户"整个逻辑是什么"）

```
爆炸瞬间（Grenade.explode）
  → 球形查询 blast_radius=8.89m 内所有 Objects 层目标（跳过 head 组防双结算）
  → 每目标：dmg = 98 × (1 − d/8.89)   ← 距离线性衰减（球体覆盖 ✓）
  → LOS 射线：爆心 → 目标胸口参考点（脚部+1.0m），排除目标自身碰撞 RID
     命中任何几何 → 该目标伤害 = 0      ← 二值全挡（本轮 1 实现）
```

问题正如用户所述：**全挡太死**——平台板 0.4m 厚、台阶沿等小厚度几何也 100% 挡伤（用户案例：雷丢在小平台下面 → 胸口射线擦过平台板 → 敌人零伤）。

## 一、爆炸伤害厚度衰减模型（本轮核心设计，用户拍板方向：墙体不能百分百挡、越厚挡越多）

### 1.1 新判定模型

保持"球体覆盖 + 距离衰减"骨架，将**二值 LOS 全挡**替换为**穿透厚度累计衰减**：

```
每目标（球内）：
  1. 距离伤害：dist_dmg = 98 × (1 − d/8.89)          （不变）
  2. 厚度累计：沿"爆心 → 目标胸口参考点"线段，以步长 δ 点采样
     （intersect_point，mask=1，排除目标自身 RID）——采样点落在实心几何内 = 计入
     T = 命中点数 × δ                                  （= 爆心到目标路径穿过的墙体总厚度）
  3. 穿透倍率：pen_mult = 衰减公式(T)                  （见 1.2，三选一待拍板）
  4. 最终伤害：dmg = dist_dmg × pen_mult
```

**几何语义**：平台板 0.4m → 只挡一小部分；rim 墙 1m → 挡更多；多层墙叠加 → 接近全挡。高低差擦边（用户案例）自然保留绝大部分伤害。

**采样参数**：步长 δ=0.25m（.tres `blast_los_sample_step`）；线段起点 = 爆心 + δ/2（半步偏移避开爆心贴面歧义）；终点 = 胸口参考点（`blast_los_probe_height` 1.0 沿用）。最坏每目标 ≤8.89m/0.25 ≈ 36 次点查询 × ≤10 目标 = 每爆 ≤360 查询，性能可忽略。

### 1.2 衰减公式（**已拍板：方案 A 线性截断**，2026-08-13 用户选择）

| 方案 | 公式 | 1m 墙 | 0.4m 平台板 | 3m 厚 | 特点 |
|---|---|---|---|---|---|
| **A 线性截断 ✅拍板** | `mult = clamp(1 − T/3.0, 0, 1)` | 挡 33% | 挡 13% | 全挡 | 直觉可预测："3 米厚全挡、1 米挡 1/3"；好调参 |
| B 指数 | `mult = exp(−T/1.5)` | 剩 51% | 剩 77% | 剩 14% | 永不完全挡（未选） |
| C 平方根 | `mult = clamp(1 − √(T/3.0), 0, 1)` | 挡 42% | 挡 26% | 全挡 | 薄墙衰减明显（未选） |

参数 `blast_penetration_max = 3.0`、`blast_los_sample_step = 0.25`（.tres，可调）。

**CS 对照注记**：CS/Source 为二值全挡（RadiusDamage trace）；本设计按用户拍板偏离为厚度衰减——注记留档。

### 1.3 既有测试语义更新（T3 六测试按新模型改写期望）

| 测试 | 旧语义 | 新语义 |
|---|---|---|
| 1m 墙（厚 1.0） | 0 伤 | dist_dmg × (1−1/3) = ×2/3 |
| 0.6m 厚矮墙贴地爆 | 0 伤 | 离散采样 T=0.5（2 点×0.25）→ ×(1−0.5/3) = ×5/6 |
| 无墙满伤 / 地板不假遮挡 / 头自挡 / 爆心抬高过顶 | 不变 | 不变 |
| integration 高空接线 | 不变 | 不变 |

采样几何与测试墙体对齐（墙厚 1.0 = 4 个采样步），期望按采样离散值推导（本轮 1 教训：离散公式逐点推导）。

## 四、TDD 断言清单

1. 换弹锁：RELOADING 中 `switch_to` → 槽位不变/状态仍 RELOADING/无 weapon_switched 信号/换弹最终完成（弹药到位）；ACTIVE 中切换照旧
2. 视图防御：`_on_switched` 后 `_reload_t < 0`（换弹动画不延续）
3. CCD：`Grenade.new()` 入树后 `continuous_cd == true`
4. 厚度采样：1.0m 墙 → T≈1.0（±δ）、pen_mult≈2/3；0.4m 板 → T≈0.4、pen_mult≈0.87；多层双墙 2m → ×1/3
5. 衰减公式（按拍板方案 A）：T=0 → 1.0；T=3.0 → 0；T=1.5 → 0.5；T>3 → 0
6. 无墙/地板假遮挡/头自挡/过顶 4 个既有测试保持绿（期望不变）
7. 全量 289 → 约 295+ 全绿
