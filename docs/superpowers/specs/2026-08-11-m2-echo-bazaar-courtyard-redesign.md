# 回声集市 v3 重设计——「院落集市」方案

> 2026-08-11 · 方向：院落迷宫式 bazaar · 60×58m · 5v5 TDM · 灰盒数据驱动
> 上位文档：docs/superpowers/specs/2026-08-10-m2-tdm-map-design.md；批判基线：map_layout.gd v2

## 1. 设计哲学

地图不是"8 个盒子 + 碎片填充"，而是**一个连续的集市建筑群**：一圈商铺带（外环体量）围出四条街与四个角院，中央是带屋顶的大市集厅。院落是从体量里"挖"出来的负空间，巷弄是体量之间的缝——先有建筑，后有院子，室内外边界靠门洞与天窗院模糊。所有屋顶在同一标高（4.8m）连成第二层战场，靠角楼（6.0m）做全图制高点与视觉锚。

## 2. 总体几何（坐标沿用现有约定：+X 东，+Z 北，墙厚 1m）

三条横截面带（西半，东侧镜像；南北向带同理）：

| 带 | x 范围 | 宽度 | 内容 |
|---|---|---|---|
| 外巷 | [-30,-23] | 7m | 慢速安全外环，大树×4，上屋顶台阶 |
| 商铺带（西带） | [-23,-16] | 7m | 外墙 [-23,-22] / 内廓 [-22,-17] 5m / 内墙 [-17,-16] |
| 西街（环市街西段） | [-16,-11] | 5m | 大厅西墙 [-11,-10] 收边 |
| 大厅 | [-11,11] × [-9,9] | 22×18 外廓 | 内廓 20×16，墙高 4.5m |

南北向同构：北带 z∈[14,21]（内墙 [14,15] / 内廓 [15,20] / 外墙 [20,21]），北环市街 z∈[9,14]，北外院 z∈[21,29]（8m 深，出生区）。
四角为转角方块 x∈[±16..±23]∩z∈[±14..±21]——**带在此连续转弯**，形成闭环体量。

- 墙高统一 4.5m（大厅/商铺带/出生建筑），边界墙 4m；屋顶板 center y=4.55、厚 0.5 → **底面 4.3m（≥4.25 ✓）、顶面 4.8m**。
- 南北严格镜像（z→-z）；**东西刻意不对称**：西带=有顶连廊（CQB），东带=三个露天院+石台（中距离）。两队体验相同，公平。

## 3. 分区设计

### Z1 大市集厅（mid 枢纽·主交战区①）
- 几何：外廓 22×18，墙 4.5m，四门 2.5m（N/S/E/W 居中）。屋顶 4.8m 整铺。
- 室内对抗：中央 3×3×2.2m LOS 亭（wall 类，高 2.2）+ 4 柱 0.6²×2.2m 于 (±2.8,±1.2) + 4 组摊位掩体（0.9m，2 盒/组，(±6.5,±4.5)，组距 5-8m 不等距）+ 2 道 1.4m 室内隔断 (±3.5,±6.5) 5m 长——**偏置门轴**，进门不撞墙腹。
- 谁压谁：占厅者四门出击、扼全图最快转点；但四门皆 2.5m 瓶颈，厅是"目标在瓶颈之后"的枢纽。手雷 20×16 ≫ 8.89m 半径，一雷清不了厅。

### Z2 厅顶+角楼（垂直枢纽）
- 厅顶 4.8m（22×18 可走），四沿 0.9m 女儿墙（蹲掩体，留台阶/桥头缺口）。
- 角楼：厅顶中央 4×4×1.2m 两级台（0.6+0.6）→ 顶面 6.0m，台上 0.9m 胸墙四沿。一侧配 0.6m 微台阶供 AI 上行。
- 对抗：角楼是全图信息位+角度位，压所有屋顶与四条街；代价——剪影暴露、四面屋顶可打、手雷可及、只有厅顶一条退路。屋顶对屋顶跨街对射 5m 间距、同标高（水平交火 ✓ ±30°）；向街俯角射击为次要用途，女儿墙+暴露剪影=成本。

### Z3 环市街（转点环· skirmish 通道）
- 几何：绕厅 5m 宽闭环，四段各 ~27m。
- 对抗：每段 1-2 组摊位簇（0.9m，聚类不等距）+ 西/东街各 2 面 2.2m LOS 屏（z=-6/+4 与 z=-4/+6，打断 28m 长视线为 8-10m 段）+ 4 座关门亭：(0,±11.5) 尺寸 2×2.2×1、(±13.5,0) 尺寸 1×2.2×2——5m 街切成两道 2m 门洞（ choke），且与厅门构成"门中门"节奏顿点。

### Z4 西带·百铺廊（西侧翼·主交战区②，CQB）
- 几何：外廓 x∈[-23,-16], z∈[-21,21]，有顶（顶 4.8），内廓 5m 宽贯通廊；**挖两个露天天井** z∈[-9,-3]、[3,9]（屋顶断开，天空+大树进廊）。
- 门：内墙 3 门 z=0(3m)、±12(2m)；外墙 3 门 z=0、±12(2.5m)；转角院另有门（见 Z6）。共 ≥8 门 ✓。
- 室内对抗：每有顶段 1 道 1.4m 隔断（左右交替偏置，zig-zag）+ 1 组 0.9m 摊位 + 1 面 2.2m LOS 屏于段口（不对称）。视线被切成 ≤12m 段。天井=手雷开放区 vs 有顶段=雷不进——东西/明暗/远近三种节奏。

### Z5 东带·石台（东侧翼·主交战区③，中距离）
- 几何：同外廓，有顶但**挖三个天井** z∈[-14,-8]、[-3,3]、[8,14]；中央有顶段地面抬 0.6m（石台，微步入）。
- 对抗：段更短（5-7m）、天井更多 → 更亮、雷更多、节奏更快；石台段是带内小高点（0.6m 高差，水平距离内角度合规）。

### Z6 角院·水井庭 ×4（转角节点）
- 转角方块内廓 5×5，L 形廊道在此汇流；中央 1.5×1.5×2.2m 水井亭（地标）+ 1 棵大树（允许贴墙）。
- 门：南面 2.5m（向环市街）、西/北面 2.5m（向外巷/外院）+ 两面 3m 敞口接廊道 = 5 个进出口。节点富集但每口都有成本。

### Z7 外巷+外院（慢速外环）
- 外巷 7m 宽（x∈[±23,±30]），大树×4/侧（z=±6、±16，对位带外门）；外院 8m 深，大树×2，出生建筑坐落其中。
- 角色：安全慢速转点（11-13s），树影=软掩体；无碎片填充，只有树+台阶。

### Z8 出生建筑 ×2（南北镜像）
- 12×6 内廓（x∈[-6,6]，北 z∈[23,29] 贴边界墙），墙 4.5m，**不封顶**（杜绝撞顶 bug 类）、内部零掩体（干净容器）。
- 门：东/西墙各 2.5m @z=±26 —— 出门即左右分岔决策。

## 4. 动线环路（3 环嵌套 + 1 垂直环）

1. **内环**（环市街）：绕厅闭环 ~100m，满速 ~16s——主轮转环。
2. **中环**（带内廊+外巷组合）：穿商铺带内廊、经角院换向 ~160m——CQB 轮转/偷袭环。
3. **外环**（外巷+外院）：~155m ~25s <30s 上限——安全慢环。
4. **垂直环**：台阶上屋顶 → 桥 → 厅顶 → 桥 → 下台阶。

转点时间（西↔东，6.35m/s）：
| 路线 | 时间 | 成本标签 |
|---|---|---|
| 穿大厅 | ~5-6s | 快，但 4×2.5m 门 choke + 厅内战 |
| 北/南环市街 | ~8-9s | 中，关门亭 + 暴露于厅门/带门火力 |
| 外巷外院 | ~11-13s | 慢，安全（树影软掩体） |
| 屋顶（台阶+双桥） | ~12-14s | 中慢，换高度信息与角度 |

出生→首接触：出生门→带外门→内门→环市街 ≈ 5-7s ✓（5-12s 窗口）；双方对称等时。

## 5. 垂直层（全部符合 ≤1.3m 直跳 / 0.6m 微台阶）

| 层 | 标高 | 可达方式 |
|---|---|---|
| 地面层 | 0 | — |
| 摊位/台面 | 0.9 / 1.2 | 直跳 ≤1.3 ✓ |
| 带屋顶 | 4.8 | 外巷贴墙微台阶 ×8 级（每级 0.6  rise，踏面 0.6，宽 1.8-2m，自 0 逐级叠盒）——西带 z=±12、东带 z=±12、北带 x=±12、南带 x=±12，共 8 座；台阶顶与屋顶边缘平接，无洞口无窄缝 |
| 厅屋顶 | 4.8 | 厅外壁贴墙台阶 2 座：西北（x∈[-13,-11], z∈[-6,-1.2]）+ 东南镜像（x∈[11,13], z∈[1.2,6]）——对角布置，南北镜像 ✓ |

- 无一处跳跃缺口（街道 5m > 4.5m 跳远上限 → 屋顶互不跳通，桥是唯一连通件=天然 choke）。

- 禁止组合：0.9 摊位与 2.2 LOS 屏间距一律 ≥1.5m（防 0.9+跳 1.39=2.29 翻上屏顶的意外 boost）。

## 6. 主题统一与地标（根治"碎片盒子汤"）

1. **一个体量**：外环商铺带连续闭环（四角转弯相接），大厅+出生建筑为独立体量——全图大形体只有 3 类，形式层级 70/25/5：大形体（带+厅+出生）≈70%，中形体（角楼/桥/井亭/关门亭/台阶）≈25%，细节（树/摊位盒）≤5%。
2. **功能逻辑**：带=商铺（廊道+摊位+隔断），厅=有顶市集（中央亭），角院=水井庭，出生=商队客栈——每个空间先有"用途"再有形体。
3. **全局 weenie**：角楼（6.0m+ 剪影，灰盒期用 4×4×1.2 台+四角 0.3×1.2×0.3 方块做钟楼轮廓）从全图任何屋顶/街道可见——"朝角楼走=回中心"，内置罗盘。
4. **东西可读差异**：西带有顶连廊（暗/密/近距），东带三天井石台（亮/疏/中距）——剪影即导航。
5. **callout 体系**（9 个）：角楼、市集厅、西桥/东桥、北门/南门（环市街关门亭）、西廊、东台、水井庭（NW/NE/SW/SE）、树影外巷、出生栋。

## 11. 风险与缓解

1. **0.6m 台阶 AI 寻路**：Godot navmesh 对台阶可能需 jump hint——M3 若不通，把每屋顶一座台阶换成 34° ramp（4.8 rise / 7m run ≤45°）。
2. **屋顶层统治**：若 playtest 屋顶过强，削角楼胸墙、桥上加 0.9 半掩体、或把带台阶从 8 座减到 4 座（只留外侧）。
3. **5m 街段一雷封锁**：关门亭两侧 2m 门洞+两侧带门 recess 提供躲避；若仍强，街宽提到 6m。
4. **屋顶板分段接缝**：天井断屋顶处必须对齐墙沿，防 <1.2m 夹缝与 Z-fighting（数据表评审项）。
5. **东西不对称学习成本**：靠 callout（西廊/东台）与剪影差异补偿，首局引导靠角楼罗盘。
6. **出生栋无顶手雷**：敌方从北带屋顶抛物进出生栋——出生栋墙 4.5m+栋深 6m，抛物角受限；若实测 spawn-grief，出生栋上方加 4.8 顶板（底面 4.3 合规，内部无跳物）。
