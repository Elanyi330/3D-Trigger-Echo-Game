## 〇、一句话定义

**Trigger Echo** 是一款纯离线的 3D 第一人称 5v5 竞技枪战游戏：玩家 + 9 个 AI（4 队友 + 5 敌人），含 **目标点占点**（可复活）与 **经典团战**（不可复活、全灭获胜）两种模式，打包为 **macOS 原生 App**，不联网、不依赖服务器。

## 一、项目目标

| 维度 | 目标 |
|------|------|
| 平台 | macOS 原生 App（.app，双击即玩，纯离线） |
| 玩法 | 5v5 第一人称枪战，两种模式：目标点占点（可复活）+ 经典团战（不可复活） |
| AI | 9 个 bot：4 队友（协同进攻/守点）+ 5 敌人（拟人化对枪），三档难度 |
| 武器 | 七大武器类（步枪/冲锋枪/霰弹枪/狙击枪/手枪/近战/投掷），v1.0.0 每类一款型号 |
| 地图 | 两张风格迥异：大图（占点模式）+ 小图（团战模式） |
| 体验 | 拟真手感（后坐力、压枪、急停），可玩性优先于画面 |
| 许可证 | 全链路合规：引擎 MIT + 自产/CC0 资产 + 代码层借鉴宽松许可项目 |

## 二、技术栈（已确认）

**引擎: Godot 4**（MIT，零授权费，原生导出 macOS .app，NavigationAgent3D 官方寻路）
**AI 路线: 混合式**（navmesh 寻路 + 轻量行为树/分层状态机决策 + 感知系统 + 拟人化瞄准参数）

```
Trigger Echo（Godot 4 项目）
├── 玩家控制器    ← FirstPersonStarter 为基础
├── 武器系统      ← Godot4-FPS-Template 的资源驱动武器
├── 射击手感      ← godot4-fps-prototype 的压枪/后坐力曲线
├── AI 决策层     ← 行为树 + 分层状态机（自研，参考多个 bot 项目）
├── AI 寻路       ← Godot NavigationAgent3D（官方）
├── AI 瞄准       ← 拟人化参数（参考 CS2-Bot-Improver 思路）
├── 回合状态机    ← 参考 CS 系 gamerules 结构（读源码不抄代码）
└── 资产          ← 程序化生成 / CC0 资源（自产优先）
```

## 四、核心玩法设计（已确认）

### 4.1 游戏模式（两种）

**模式一：目标点占点（大图，可复活）**
- 1 个中立目标点（如"信号塔"），进攻方占据后需守住 30 秒，防守方需阻止
- 回合限时 2 分钟；**玩家死亡后可在己方安全区复活**（复活冷却）
- 按回合计分：占点成功 1 分，率先达到目标分（如 7 分）获胜

**模式二：经典团战（小图，不可复活）**
- 双方 5v5 全灭对方即获胜（Team Deathmatch 无复活规则）
- **无复活**：死亡后观战至本局结束，全灭判定胜负
- 打满 7 局先胜 4 局获胜（或按局数限制）

### 4.2 武器系统（七大武器类 · 具体型号与数值）

#### 4.2.1 战斗基础规则（统一）

- **所有单位血量统一 100 HP**（玩家与 9 个 AI 完全一致，v1.0 无护甲系统）
- 伤害部位倍率：**头部 ×2.5（全武器爆头倍率上限，统一采用 2.5）** / 躯干 ×1 / 四肢 ×0.8；**例外：狙击枪 ×1.5（躯干 80 大残 → 爆头 120 必杀）；霰弹枪仅中心弹丸 ×1.5**
- **一枪必杀判定**：单发伤害 × 倍率 ≥ 100 才可一枪击杀——v1.0 仅 AWM 爆头（120）满足（AK-47 爆头 62.5、战术匕首头部 87.5 均大残，需补枪）
- **TTK 设计基调**：躯干击杀 4-6 发（步枪 4 发、冲锋枪 5 发、手枪 5 发收）；霰弹近距 2 发；狙击躯干 2 发（大残后需补枪）；手雷大残不秒杀
- 伤害衰减：**分段阶梯衰减曲线**（非线性）——有效射程内满伤；有效→最大射程间按武器表分段递降；衰减下限永不为 0（各武器表标注最低伤害比）；霰弹枪为弹丸独立衰减（见 4.2.3 ③）
- 命中判定：枪械统一 hitscan（参考 q1k3 射线判定思路），投掷物为弹道
- 数值调校依据：基准参考 CS 系社区数值与 OpenArena g_weapon.c 参数化样本，最终以 TDD 测试驱动调参为准

#### 4.2.2 武器参数统一字段（每款武器必含）

| 字段 | 说明 |
|------|------|
| 伤害 | 躯干基准伤害 |
| 爆头倍率 | 头部倍率（统一 ×2.5 上限，狙击/霰弹 ×1.5 例外） |
| 射速 | 每分钟射速 RPM（或单发间隔） |
| 负载（弹匣容量） | 单次装填可发射数 |
| 备弹 | 总携带弹药 |

| 伤害衰减曲线 | 分段阶梯：各距离段的伤害比值（如 0-有效=1.0 / +50%射程=0.8 / +100%=0.65） |

| 字段 | 数值 | 字段 | 数值 |
|------|------|------|------|

| 穿透 | 0 | 移速 | -6% |
| 切枪 | 1.0s | 模式 | 泵动 · hitscan（散射） |

**独特机制——弹丸运行精细化设计（v1.0 重点规格）**：
- **逐弹丸独立射线**：每发 7 颗弹丸各自独立 raycast + 独立伤害结算 + 独立命中反馈（弹孔/粒子），弹丸间互不影响
- **落点分布**：弹丸在锥角内按**高斯分布**落点（中心密集、边缘稀疏），非均匀圆盘——保证近距"核心弹丸大概率命中"
- **逐弹丸独立衰减**：每颗弹丸按自身射线飞行距离查衰减曲线（8m 内 11 → 8-15m 为 8 → 15m+ 为 5），**远距单颗弹丸伤害上限 5**，不存在"远距仍全中"的失真
- **远距有效弹丸数收缩**：距目标 >10m 时，命中弹丸数上限收缩至 3-4 颗（模拟弹丸散开飞出判定盒）——远距最大理论伤害 = 4×8 = 32（大残以下），必须贴近至 2m 内才有 77 满伤
- **近距判定**：2m 内所有弹丸必然命中（不计散布），保证"贴身一发致残/二发击杀"（77×2=154）
- **击杀节奏**：2m 内 2 发击杀（77×2）；8-15m 理论 3-4 发

| 后坐力 | 垂直 0.5° 水平 ±0.3° | 首发倍率 | ×1.6 |
| 恢复 | 14°/s | 散布 | 腰射 2.8° / 开镜 1.0° |
| 穿透 | 0.5 面 | 移速 | 0% |
| 切枪 | 0.4s（最快） | 模式 | 半自动 · hitscan |

**独特机制**：切枪最快——主武器换弹/弹药耗尽时应急拔枪；**躯干 5 发（22×5=110）**、爆头 55 大残 + 3 发躯干补枪

##### ⑥ 战术匕首「回声」— 近战（默认武器）
| 字段 | 数值 | 字段 | 数值 |
|------|------|------|------|
| 伤害 | 躯干 35 / 头部 87.5（×2.5） | 爆头 | ×2.5（35×2.5=87.5） |
| 挥击间隔 | 0.45s | 范围 | 1.5m 扇形 60° |
| 弹药 | 无 | 换弹 | 无 |
| 移速 | 0% | 切枪 | 0.5s |

**独特机制**：**躯干 3 刀击杀（35×3=105）、头部 2 刀击杀（87.5+35=122.5）**——近战需要贴近身位连击，无背刺奖励、无部位例外（头部倍率同统一上限 ×2.5）；击杀可显示专属处决反馈

##### ⑦ M67「轰鸣」— 破片手雷（附加武器）
| 字段 | 数值 | 字段 | 数值 |
|------|------|------|------|
| 伤害 | 中心 90（2m 内）→ 5m 处 30 | 爆头 | 无（范围伤害） |
| 引信 | 3.5s | 投掷距离 | 25m |
| 爆炸半径 | 6m（2m 内 90 / 4m 内 60 / 6m 边缘 30） | 携带 | 1 枚 |
| 命中判定 | 弹道（抛物线） | 移速 | 0% |

**独特机制**：**中心 90 大残不秒杀（100→10 HP）**——手雷是"逼走位/收割残血"工具而非一击必杀；爆炸产生**强枪声事件**（AI 听觉感知半径 30m，参考 mtrebi/AI_FPS 感知设计）；投掷物为物理弹道，可被反弹；**持有手雷时按住右键可取消投掷**（保留弹药）

#### 4.2.4 携带规则

一场战斗最多携带 **主武器 ×1 + 副武器 ×1 + 默认武器（近战）×1 + 附加武器 ×1**；主武器四类中择一，副武器手枪固定，近战默认携带，投掷武器可选携带（按需取舍）。

#### 4.2.5 配置化与扩展

全部武器数值走 `Weapon_Resource` 资源配置（参考 Godot4-FPS-Template），`weapon_*.tres` 文件即武器数值唯一来源，测试与调参均作用于资源文件。未来版本在每类下增加细分型号（如步枪类增加 M4/M16 变体），只需新增资源文件与压枪曲线，代码零改动。

### 4.4 AI 设计（项目技术难点核心）
**9 个 bot 采用混合式 AI，分层：**
1. **导航层**：Godot NavigationAgent3D（官方寻路）
2. **感知层**：视线/遮挡检测 + 听觉（脚步声/枪声事件），参考 mtrebi/AI_FPS
3. **决策层**：轻量行为树（5-10 节点，参考 BehaviorTree 思路）+ 分层状态机（待机/巡逻/追击/交战/守点/撤退）
4. **反应层**：拟人化对枪（瞄准加速度、反应时间 150-400ms、压枪误差），参考 CS2-Bot-Improver 人格参数思路
5. **团队层**：角色分配（突击/支援/狙击/守点）+ 简单呼叫（报点/请求支援），参考 Q3 ai_team.c 思路

**三档难度（简单/普通/困难）**：以拟人化参数化实现，天然支持多档——
| 参数 | 简单 | 普通 | 困难 |
|------|------|------|------|
| 反应时间 | 400-700ms | 250-450ms | 150-250ms |
| 瞄准误差 | 大 | 中 | 小 |
| 压枪精度 | 低 | 中 | 高 |
| 感知范围 | 缩短 | 标准 | 延长 |
