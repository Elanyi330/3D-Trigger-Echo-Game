# Trigger Echo

> 纯离线 3D 第一人称 5v5 竞技枪战游戏（玩家 + 9 个 AI）
> Godot 4 | macOS 原生 App | 不联网、不依赖服务器

## 项目简介

**Trigger Echo** 是一款纯离线的 3D 第一人称 5v5 竞技枪战游戏：玩家与 4 名 AI 队友并肩作战，对抗 5 名 AI 敌人。包含**目标点占点**（可复活）与**经典团战**（不可复活、全灭获胜）两种模式，打包为 macOS 原生 App，双击即玩。

**核心体验：** 拟真手感优先（后坐力、压枪、急停），AI 拟人化对枪（反应时间、瞄准误差、压枪精度随三档难度差异化），9 个 bot 协同进攻/防守，让单人玩家获得接近真实 5v5 竞技的对抗体验。

**技术路线：** Godot 4 引擎（MIT，零授权费）+ 混合式 AI（navmesh 寻路 + 行为树 + 分层状态机 + 感知系统 + 拟人化瞄准参数）+ 资源驱动武器系统，全链路许可证合规。

## 核心玩法

### 游戏模式（两种）

| 模式 | 地图 | 规则 |
|------|------|------|
| **目标点占点** | 大图「回声哨站」（约 60m×60m） | 1 个中立目标点，攻方占据后守 30 秒；回合限时 2 分钟；死亡可在己方安全区复活；按回合计分，先达 7 分获胜 |
| **经典团战** | 小图「弹痕仓库」（约 30m×30m） | 5v5 全灭对方即获胜；无复活（死亡观战至局末）；打满 7 局先胜 4 局 |

### 武器系统（七大武器类 · v1.0.0 各一款）

- **AK-47「铁幕」**（步枪）— 躯干 4 发击杀，首发上跳显著，压枪门槛高
- **MP5「蜂鸟」**（冲锋枪）— 躯干 5 发击杀，移动射击精度损失小，近距机动流
- **M870「碎颅」**（霰弹枪）— 7 弹丸逐颗独立结算，2m 内 2 发击杀
- **AWM「远山」**（狙击枪）— 躯干 80 大残 + 爆头 120 一枪必杀，开镜呼吸抖动 + 屏息
- **Glock 17「迅捷」**（手枪）— 切枪 0.4s 最快，应急拔枪
- **战术匕首「回声」**（近战）— 躯干 3 刀 / 头部 2 刀击杀
- **M67「轰鸣」**（破片手雷）— 中心 90 大残不秒杀，逼走位/收割残血

**战斗基础：** 所有单位统一 100 HP；部位倍率 头 ×2.5 / 躯干 ×1 / 四肢 ×0.8（狙击/霰弹 ×1.5 例外）；分段阶梯伤害衰减；枪械 hitscan、投掷物物理弹道；携带规则 主武×1 + 副武×1 + 近战默认 + 投掷可选。

### AI 系统（9 个 bot · 三档难度）

五层混合式 AI：导航（navmesh 寻路）→ 感知（视线/遮挡/听觉）→ 决策（行为树 + 分层状态机）→ 反应（拟人化对枪参数）→ 团队（角色分配 + 呼叫支援）。

三档难度（简单/普通/困难）以拟人化参数实现：反应时间 150-700ms、瞄准误差、压枪精度、感知范围差异化。

## 快速开始

```
# 1. 克隆仓库
git clone git@github.com-trigger-echo:Elanyi330/3D-Trigger-Echo-Game.git

# 2. 环境检查（需要 Godot 4.7.1）
bash tools/setup_env.sh

# 3. 运行游戏（M0 后：WASD 移动 / Space 跳 / Shift 下蹲）
godot --path .

# 4. 运行测试（GUT，headless）
godot --headless -s addons/gut/gut_cmdln.gd
```

> 注：`godot --path .` 启动 M0 主场景 L_Main.tscn（自建简化测试场景，非正式关卡，见下方开发文档说明）。
