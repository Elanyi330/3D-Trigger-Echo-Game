**规则**：
- 视模型（第一人称持枪）= 真实长度 × **1.4**（FPS 行业惯例，CS/COD 屏幕占比）
- 世界模型（敌人/队友持枪）= 真实长度 × 1.0
- **新下载模型必须按此归一化**（Blender 脚本统一处理：缩放 + 居中 + 导出）

## 二、模型格式与朝向

- 格式：**glTF (.glb)**（Godot 4 原生导入）
- 朝向：建模时枪口方向明确，导入 Godot 时烘焙对齐（枪口 -Z）
- 原点：模型中心（武器）或足底（角色）
